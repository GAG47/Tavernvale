## 正式输入与输出

Arcane Ecology 是 Arcane Environment 之后的纯确定性分类阶段。正式输入严格只有两条彼此独立的连续轴：

- `ArcaneEnvironmentLayer.mana_concentration`：当地当前实际存在的 Mana 数量。
- `ArcaneFieldLayer.background_arcane_potential`：当地天然让 Mana 转化为持续魔法效应的潜在能力。

`ArcaneEcologyLayer` 严格只保存两个 Cell-aligned `PackedInt32Array`：

- `arcane_ecology_state`：`NORMAL`、`INFLUENCED`、`DOMINANT`。
- `arcane_manifestation_type`：`NONE`、`CRYSTALLINE`、`ECOLOGICAL`、`MIXED`。

Band 只在生成与 Debug 诊断时即时计算，不保存到正式 Layer。Generator 不接收 SpatialGraph、自然生态或其他自然地理 Layer，也不读取 Background Mana、Background Stability、Mana Flowability 或 Mana Stability。

## 固定 Band Thresholds

Mana Concentration 与 Background Arcane Potential 使用相同的绝对阈值：

| Band | 范围 |
|---|---|
| LOW | `value < 0.60` |
| MEDIUM | `0.60 <= value < 0.70` |
| HIGH | `value >= 0.70` |

Settings 只含四个阈值参数，默认均为对应轴的 `0.60 / 0.70`；validation 要求 finite 且 `0 <= medium < high <= 1`。对正式 `PackedFloat32Array` 输入使用其存储精度下的阈值比较，targeted test 确认 `0.599999 / 0.600000 / 0.699999 / 0.700000` 分别进入 `LOW / MEDIUM / MEDIUM / HIGH`。

## 完整 3×3 Rule Table

| Mana Band | Potential Band | Arcane Ecology State | Manifestation Type |
|---|---|---|---|
| LOW | LOW | NORMAL | NONE |
| LOW | MEDIUM | NORMAL | NONE |
| LOW | HIGH | NORMAL | NONE |
| MEDIUM | LOW | NORMAL | CRYSTALLINE |
| MEDIUM | MEDIUM | INFLUENCED | MIXED |
| MEDIUM | HIGH | INFLUENCED | ECOLOGICAL |
| HIGH | LOW | NORMAL | CRYSTALLINE |
| HIGH | MEDIUM | INFLUENCED | MIXED |
| HIGH | HIGH | DOMINANT | MIXED |

Generator 逐 Cell 只做两次固定 Band 分类与上表查分支；没有随机、Noise、综合连续分数、邻域、平滑、传播或区域后处理。
