# Tavernvale v1.3.1 — Climate Precipitation Fix

- Version: v1.3.1
- Date: 2026-08-29
- Commit: 未提交（工作区实现）

## 目标

对 v1.3 Preliminary Climate 做三项限定修正：让寒冷地区继续计算总降水、使用非线性 Precipitation Debug 色阶，并补充四个降水分位数。除此之外不调整 Climate 参数或其他世界生成系统。

## 修改内容

- 删除风传递中 `temperature[current] < -5.0` 时跳过 Cell 的限制。
- 降水生成不再把 `temperature` 数组传入 `_generate_precipitation()` 与 `_pass_wind()`；温度仍作为独立正式 Climate 输出生成。
- Precipitation Debug 的显示归一化从线性比例改为比例平方根。
- Precipitation Debug 在 Min / Max / Mean 后增加 P25、P50 / Median、P75 与 P90。
- 复用现有固定世界测试，增加寒冷 Cell 存在且至少有寒冷 Cell 获得降水的断言；没有增加世界或 Seed 批量生成。

## 关键实现

### 寒冷地区总降水

删除的限制为：

```gdscript
if temperature[current] < -5.0:
    continue
```

现在所有 Cell 都执行同一套既有水面补湿、海岸增雨、陆地水汽损失和地形降水逻辑。`precipitation` 表示总降水，不区分雨雪。本次没有实现积雪、融雪、雪线或冰川，也没有修改盛行风、海岸增雨、纬度 modifier、地形雨或湿度损失参数。

### Debug 色阶

正式 `precipitation` 数组没有任何显示用变换。仅在 `_precipitation_color()` 中使用：

```text
normalized = sqrt(clamp(precipitation / max_precipitation, 0, 1))
```

之后继续使用原有棕 → 绿 → 青 → 蓝 → 深蓝渐变。平方根拉伸提高中低降水值在色阶中的位置，减少大面积区域聚集在棕色端的问题；海洋没有单独显示分支。

### 分位数

Climate Debug 统计生成时复制并升序排序正式降水数组，不修改原数组。P25、P50、P75、P90 使用线性插值分位数：

```text
position = (cell_count - 1) * percentile
result = lerp(sorted[floor(position)], sorted[ceil(position)], fract(position))
```

默认 Seed 1、Continents、20000 Cells 的实际 Debug 统计为：

- Min `0.00`
- Max `61.45`
- Mean `13.23`
- P25 `5.95`
- P50 / Median `17.84`
- P75 `17.84`
- P90 `17.84`
