# v2.5 — Arcane Resource Potential

Date: 2026-09-07
Baseline: `237b137` (`main`, v2.4.1)

## Formal semantics

v2.5 adds a pure downstream, Cell-aligned world-scale potential layer. Its place in future realization is:

```text
World Potential
    -> Region Resource Realization
    -> Location concrete resources
    -> Scene interactive resources
```

**Potential ≠ Deposit ≠ Production.** v2.5 does not generate concrete elements, quality, resource types, reserves, deposits, production, extraction difficulty, or economic value.

明确说明：v2.5 不生成具体元素、品质、资源类型或储量。

The formal `ArcaneResourcePotentialLayer` contains exactly four `PackedFloat32Array` outputs in `[0, 1]`:

- `arcane_energy_potential`: usable natural Mana-energy potential.
- `arcane_material_potential`: broad, non-biological common magical-material potential.
- `arcane_bioresource_potential`: renewable or cultivable biological magical-resource potential.
- `rare_arcane_resource_potential`: independently concentrated rare and high-value magical-resource potential.

No total or universal magical-resource score is produced.

## Formal formulas

All input clamping below is defensive; Generator validation rejects non-finite or out-of-range formal inputs before evaluation.

### Arcane Energy

```text
C = clamp(mana_concentration, 0, 1)
F = clamp(mana_flowability, 0, 1)
energy = clamp(C * (0.70 + 0.30 * F), 0, 1)
```

Energy reads no Background Arcane Potential, Mana Stability, Manifestation, Geology, or noise.

### Arcane Material

```text
C = clamp(mana_concentration, 0, 1)
G = sqrt(province_factor * material_factor)
mana_support = sqrt(C)
geology_support = 0.60 + 0.40 * G
manifestation_support = 0.75 + 0.25 * M_mat
material = clamp(mana_support * geology_support * manifestation_support, 0, 1)
```

Manifestation and Geology enrich the result but never act as hard gates.

### Arcane Bioresource

```text
C = clamp(mana_concentration, 0, 1)
P = clamp(background_arcane_potential, 0, 1)
terrestrial_host = sqrt(clamp(vegetation_potential, 0, 1))
aquatic_host = max(freshwater_aquatic_potential, coastal_aquatic_potential)
B = max(terrestrial_host, aquatic_host)
arcane_ecology_support = sqrt(clamp(C * P, 0, 1))
biological_host_support = 0.20 + 0.80 * B
bioresource = clamp(arcane_ecology_support * biological_host_support * M_bio, 0, 1)
```

The formal `0.20` host baseline permits a low result under strong Arcane Ecology even when the natural host is zero. Aquatic suitability is consumed from Natural Resource Potential; Climate and Hydrology are not re-read.

### Rare Arcane Resource

```text
rare_host = max(energy, material, bioresource)
unit_noise = clamp((raw_noise + 1) * 0.5, 0, 1)
rare_concentration = smoothstep(0.60, 0.92, unit_noise)
rare = clamp(rare_host * rare_concentration, 0, 1)
```

Rare has no baseline: zero concentration always produces zero Rare Potential.

## Rare deterministic concentration channel

- Salt: `0x52415245` (`RARE`).
- Scale: `4.0` normalized world-space units on both axes.
- Channel seed: `DeterministicRng.stable_mix(world_seed, salt)`.
- Noise: `TYPE_SIMPLEX_SMOOTH`, `FRACTAL_FBM`, 3 octaves, gain `0.50`, lacunarity `2.0`, frequency `1.0`.
- Domain warp: disabled.
- No per-Cell RNG, Cell-ID seed, or per-world normalization.
- Existing BASE, PREC, MANA, STAB, and POTL salts are unchanged.
