# v2.6 — Arcane Hazard Potential

Date: 2026-09-07
Baseline: `0421507` (`main`, v2.5)

## Formal semantics

v2.6 adds a pure downstream, Cell-aligned world-scale environmental hazard layer. The formal progression is:

```text
Arcane Hazard Potential
    -> Civilization Exposure / Vulnerability
    -> Disaster Risk
    -> Event Realization
    -> Concrete disaster and damage
```

**Hazard Potential ≠ Disaster Event ≠ Disaster Damage.** v2.6 generates no event probability, rate, type, ID, damage, loss, casualty, settlement effect, or resource loss.

The `ArcaneHazardPotentialLayer` contains exactly three `PackedFloat32Array` outputs in `[0, 1]`:

- `arcane_hazard_activity_potential`: long-term tendency to sustain anomalies or disturbances; not an annual event probability or frequency.
- `arcane_hazard_severity_potential`: world-scale environmental upper basis for the Mana magnitude and persistent effect available if an anomaly occurs; not realized damage.
- `arcane_hazard_propagation_potential`: tendency for an existing anomaly to spread through the local Mana environment; not a realized path, radius, speed, or distance.

No unified Hazard Score is generated because Activity, Severity, and Propagation intentionally support different regimes: frequent-small, rare-severe, severe-local, and moderate-but-highly-propagating hazards.

## Inputs, responsibilities, and formulas

The Generator accepts only `ArcaneFieldLayer` and `ArcaneEnvironmentLayer`, and reads only:

- `S = mana_stability`: whether sustained instability is likely.
- `C = mana_concentration`: how much Mana can participate if an anomaly occurs.
- `F = mana_flowability`: how readily an anomaly can propagate.
- `P = background_arcane_potential`: how readily Mana can form persistent magical environmental effects.

All helpers defensively clamp inputs, while Generator validation rejects non-finite or out-of-range upstream values first.

```text
Activity = clamp((1 - S) * (0.70 + 0.30F), 0, 1)
Severity = clamp(C * (0.70 + 0.30P), 0, 1)
Propagation = clamp(F * (0.60 + 0.40C), 0, 1)
```

Activity does not read Concentration or Potential. Severity does not read Stability or Flowability. Propagation does not read Stability or Potential.

Arcane Forcing is not read directly because final `mana_stability` already combines persistent forcing, transport imbalance, and restoration. Reading source/sink or disturbance diagnostics again would double-count instability. No Settings, noise, RNG, seed, world position, natural geography, Ecology, Manifestation, or Resource Potential is consumed.

Disaster types are deferred to event realization, where Hazard Potential may later be combined with polarity, Manifestation, natural context, and civilization state. Defining a type in v2.6 would incorrectly turn environmental potential into a realized event.

## Debug integration

No separate Arcane Hazards page was created. Following the final debug-UI organization, the three continuous hazard views are colocated with the four Arcane Resource Potential views on the existing `Arcane Resources` page:

- Hazard Activity
- Hazard Severity
- Hazard Propagation

The Cell Inspector calculates instability and other explanatory terms on demand; none are stored in the production Layer. All seven views on `Arcane Resources` remain keyboard-accessible through `1`–`7`.
