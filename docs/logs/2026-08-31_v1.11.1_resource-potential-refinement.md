# v1.11.1 Resource Potential Refinement

- Version: v1.11.1
- Date: 2026-08-31
- Commit: 未提交

## Scope

本版本只修正 Natural Resource Potential 的 Coastal Aquatic 与 Forage，并增强统一 World Debug。Agriculture、Timber、Construction Stone、Base Metal、Precious Mineral 与 Freshwater Aquatic 数值算法完全保持 v1.11；没有修改任何 Terrain、Climate、Hydrology、Geology、Surface Water、Ecology 或 Soil 算法与参数。

## Coastal Aquatic

正式 Terrain 使用 `[-100, 100]` normalized height，Ocean 为 `[-100, 0)`。对 Ocean Cell：

```text
ocean_depth = max(-terrain_height, 0)
shelf_suitability = 1 - smoothstep(20, 60, ocean_depth)

coastal_aquatic = temperature_suitability
                   × (0.45 + 0.35 × shelf_suitability
                           + 0.20 × estuary_strength)
```

仍然只写入邻接 Land 的真实 Coastal Ocean Cell；estuary 仍只识别直接流入该 Ocean Cell 的正式 River Cell。没有加入 Ocean Current、Upwelling、Marine Nutrients、Marine Biome、Coral Reef 或多 Cell 河口搜索。

`ResourcePotentialSettings` 新增：

- `coastal_shallow_shelf_depth = 20.0`
- `coastal_deep_shelf_depth = 60.0`

## Freshwater Aquatic 语义

算法完全不变：仍然只使用正式 River Strength、真实 Lake Habitat 与 Temperature Suitability，Ocean 为 0。

`freshwater_aquatic_potential` 表示 freshwater aquatic biological / fishery potential，即区域尺度淡水水产与渔业资源潜力；它不是 Freshwater Availability、饮水条件、灌溉水源或人口供水能力。普通非正式溪流没有被加入本层。

## Forage

Biome factor table 与 Soil Support 不变，只将 raw `vegetation_potential` 乘数映射为草本生产语义：

```text
forage_growth_support = smoothstep(0.10, 0.50, vegetation_potential)
forage = forage_growth_support × open_land_factor × (0.75 + 0.25 × fertility)
```

这不是 per-world normalization。`ResourcePotentialSettings` 新增：

- `forage_vegetation_low = 0.10`
- `forage_vegetation_full = 0.50`

## Debug

- Resources Page 的八个 View 顺序保持不变。
- `H` 成为全局 Terrain Height reference，直接切到 World / Terrain Height。
- `B` 成为全局 Biome reference，直接切到 Ecology & Soil / Biome。
- 所有 Cell Inspector 使用公共 header，固定首先显示 Cell ID、Height、Biome。
- Forage Inspector 增加 Forage Growth Support、Open-land Factor 与 Soil Support。
- Coastal Inspector 增加 Ocean Depth、Shelf Suitability、Temperature Suitability 与 Estuary Strength。
- Freshwater Inspector/Layer 注释明确 Aquatic = fishery / aquatic biological resource，不是 drinking-water availability。
- Coastal HUD 额外显示 Shelf Suitability Mean/P50/P75/P90。

## H / B Hold Reference 修正

后续 Debug 验收发现，最初的 H/B 实现会真正修改 `debug_page` 与 `view_mode`。v1.11.1 内已修正为独立的临时 Map Renderer Override：

- 按住 `H`：地图临时使用现有 Terrain Height renderer。
- 按住 `B`：地图临时使用现有 Biome renderer。
- 松开：地图恢复当前最新的正式 `debug_page/view_mode`。
- Reference 激活期间，Page、View、右侧统计与 Cell Inspector 均保持当前正式系统语义。
- H/B 同时按住时最后按下者优先；释放优先项后，如另一键仍按住则恢复另一 Reference。
- Reference 激活期间 Tab、Shift+Tab、1~9 仍可更新正式 Page/View；释放 Reference 后显示更新后的最新 View。
- World / Terrain Height 与 Ecology & Soil / Biome 的正常 Page + 数字导航完全保留。

Panel 仅额外显示当前 `Reference: Terrain Height/Biome`，快捷键说明改为 `Hold Height/Biome Reference`。这次修正只影响 Debug UI 状态和地图颜色源，没有修改任何 Resource 或 WorldGen 正式数据。
