# Tavernvale v1.2 — Debug Statistics Fix

- Version: v1.2
- Date: 2026-08-29
- Commit: 未提交（工作区实现）

## 目标

修复 v1.2 Debug View 在 Terrain Height 与 Land / Water 模式下仍显示 Raw Composition 统计的问题，使右侧统计内容与当前显示模式一致。

## 修改内容

- 保留 Raw Composition 模式原有的 Composition 统计。
- 新增基于 `TerrainHeightLayer.terrain_height` 的最小值、最大值、平均值、陆地比例与水域比例统计。
- Terrain Height 模式显示高度统计及陆海比例。
- Land / Water 模式只显示陆海比例。
- Terrain 统计仅在重新生成 Composition 与 Terrain layer 后计算一次，切换显示模式不重新扫描 Cell。
- 未修改 `TerrainHeightProjector`、Composition Generator 或生成算法，未新增测试文件。

## 修改文件

- `tests/worldgen/composition/world_composition_debug_view.gd`
- `docs/logs/2026-08-29_v1.2_debug-statistics-fix.md`

## 关键实现

Debug View 使用独立的 `_terrain_statistics` 字典保存：

- `min_height`
- `max_height`
- `mean_height`
- `land_ratio`
- `water_ratio`

陆地数量通过 `TerrainHeightLayer.is_land(cell_id)` 统计，其真值仍为 `terrain_height[cell_id] >= 0.0`；水域比例为 `1.0 - land_ratio`。`_append_mode_statistics()` 根据当前 `ViewMode` 选择需要追加到信息面板的统计行。
