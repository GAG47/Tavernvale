# v3.0.2 — World-scale Groundwater & Aquifer

## 目标

v3.0.2 在冻结的 v3.0.1 Subsurface Strata 之上新增 World-scale Groundwater
事实，并将地下水与任意 absolute z 的实际岩层组合成派生 Aquifer 查询。World 层只描述长期、
宏观地下水条件；没有引入地下水流向、压力网络、3D 水格、泉眼、地下河、季节变化或固定活跃
地下水底界。

## 正式输出与输入

`GroundwaterLayer` 只保存三个等长于 Cell Count 的数组和一份 Settings：

- `groundwater_supply: PackedFloat32Array`，范围 `[0, 1]`；
- `water_table_z: PackedFloat32Array`，为 absolute world z；
- `groundwater_salinity_class: PackedInt32Array`，枚举为 `FRESH / BRACKISH / SALINE`；
- `settings: GroundwaterSettings`。

生成输入为 `SpatialGraph`、Final `TerrainHeightLayer`、Final `WorldClimateLayer`、
`WorldHydrologyLayer`、`SurfaceWaterLayer` 和 `GroundwaterSettings`。生成器无 seed，且不依赖
Subsurface Strata；Strata 仅在 Aquifer 查询阶段参与。生成器不修改任何输入。

## 锁定公式

普通陆地的气候补给为：

```text
climate_supply = precipitation / (precipitation + precipitation_reference)
```

每个正式 River Cell 使用现有 `EcologyGenerator.river_strength_for(...)` 作为源强度，按真实
world-space graph edge distance 在 40 范围内传播。每个 Lake Cell 以 1.0 为源强度，在 60
范围内传播。两者均使用：

```text
falloff = 1 - smoothstep(0, radius, distance)
```

多个同类源对目标 Cell 取最大值，不相加；Ocean 不作为 River/Lake recharge 传播通道。
普通陆地最终为：

```text
surface_water_influence = max(river_influence, lake_influence)
groundwater_supply = clamp(climate_supply + 0.30 * surface_water_influence, 0, 1)
```

Ocean 和 Lake 的 `groundwater_supply` 固定为 1。没有用 surface Material permeability、
Ecology moisture、drainage、temperature、evaporation 或 noise 修正补给。

普通陆地地下水位为：

```text
base_depth = lerp(50, 6, sqrt(groundwater_supply))
highland_factor = smoothstep(40, 80, terrain_z)
water_table_depth = base_depth + 20 * highland_factor
water_table_z = terrain_z - water_table_depth
```

Ocean / Lake 的 `water_table_z = terrain_z`。没有额外 clamp 或固定地下 floor。

Marine Influence 由所有 Ocean Cell 作为 distance 0 的 multi-source Dijkstra 源，在真实
world-space graph distance 50 内计算同一 falloff。普通陆地：

```text
salinity_pressure = marine_influence * (1 - groundwater_supply)
pressure < 0.20       -> FRESH
0.20 <= pressure < .60 -> BRACKISH
pressure >= 0.60      -> SALINE
```

Ocean 直接为 `SALINE`，Lake 直接为 `FRESH`。

## Aquifer 派生规则

`GroundwaterLayer` 提供 water-table depth、是否位于水位以下、active groundwater、Aquifer
Yield 和 Aquifer Class 查询。水位以下的活跃地下水连续随深度衰减：

```text
depth_below_water_table = water_table_z - z
depth_factor = pow(0.5, depth_below_water_table / 50)
active_groundwater = groundwater_supply * depth_factor
```

水位以上返回 0。查询位置无岩石时 Aquifer Yield 也为 0；否则直接复用当前 Material 的
`GeologyCatalog.permeability_for(material)`：

```text
aquifer_yield = clamp(active_groundwater * permeability, 0, 1)
yield < 0.18        -> NONE
0.18 <= yield < .45 -> LIGHT
yield >= 0.45       -> HEAVY
```

Aquifer 不存为 Cell 数组，没有新增 Material 标签或第二套 permeability 表。

## Debug

World Composition Debug 新增独立 `Groundwater` 页面：

1. Groundwater Supply；
2. Water Table Depth；
3. Groundwater Salinity；
4. Aquifer Class @ z=-25；
5. Aquifer Class @ z=-75。

Supply 使用固定 `[0, 1]` 陆地色阶，Water Table Depth 使用固定参数范围；两者均单独显示
Ocean/Lake。Salinity 与 Aquifer 使用离散类别色。Aquifer slice 将无岩石/高于 terrain 明确显示为
light blue，不混入 NONE Aquifer。

Cell Inspector 显示 precipitation、climate supply、River source/strength/influence、Lake
source/influence、surface-water influence、Groundwater Supply、Water Table z/depth、Salinity、
Marine Influence 和 Salinity Pressure；Aquifer slice 额外显示 slice z、水位关系、active
groundwater、Material、permeability、Yield 和 Class。所有中间值只在 Debug 即时计算，不进入
正式 Layer。

## 版本边界

本实现没有修改 v3.0.1 Subsurface Strata 的算法、参数、数据结构或输出，也没有修改现有
Material permeability。所有 v3.0.2 参数均保持设计默认值，未自动调参。
