# v1.11 Natural Resource Potential

- Version: v1.11
- Date: 2026-08-31
- Commit: 未提交

## 目标与语义

在 Soil 之后增加只读的 World-scale `ResourcePotentialLayer`，将现有自然地理结果派生为八类 `[0, 1]` 环境适宜度 / geological prospectivity。

**Potential ≠ Deposit ≠ Production。** 本层不表示资源一定存在、储量、产量、发现难度、开采难度或经济价值。后续层级预期为：

```text
World Potential
    ↓
Region Deposit / Resource realization
    ↓
Location 具体资源结构
    ↓
Scene 可交互资源节点
```

## 正式输出

`ResourcePotentialLayer` 包含八个与 Cell 对齐的 `PackedFloat32Array`：

- `agriculture_potential`
- `timber_potential`
- `forage_potential`
- `construction_stone_potential`
- `base_metal_potential`
- `precious_mineral_potential`
- `freshwater_aquatic_potential`
- `coastal_aquatic_potential`

所有输出均 clamp 到 `[0, 1]`。

## 派生规则

- Agriculture：Soil Fertility / Depth / Texture、Final Temperature、Ecological Moisture、Drainage 与正式 Soil slope factor；使用需求指定的 `soil_quality`、climate geometric mean 与 terrain support 加权幂乘公式。
- Timber：`vegetation_potential × woody_biome_factor × (0.70 + 0.15 depth + 0.15 fertility)`。
- Forage：`vegetation_potential × open_land_factor × (0.75 + 0.25 fertility)`。
- Construction Stone：Geology Material suitability × `(1 - 0.25 soil_depth)`。
- Base Metal：`sqrt(province × material) × (0.25 + 0.75 concentration)`。
- Precious Mineral：`sqrt(province × material) × precious_concentration`，无 baseline。
- Freshwater Aquatic：`max(formal_river_strength, lake_habitat) × temperature_window`；Ocean 为 0。
- Coastal Aquatic：只写入邻接 Land 的实际 Ocean Cell，`temperature_window × (0.65 + 0.35 estuary_strength)`；河口只认直接流入该 Ocean Cell 的正式 River Cell。

Ocean / Lake 上六类陆地资源为 0；内陆 Coastal Aquatic 为 0；Ocean Freshwater Aquatic 为 0。

## 连续矿化场

Base Metal 与 Precious Mineral 使用两个独立、稳定 salt，经 seed avalanche 形成独立 FastNoiseLite channel。噪声按 normalized world position 连续采样，默认 scale 分别为 `3.0` 与 `4.0`，不绑定 Cell ID 或 Voronoi 顺序。

- Base concentration：`smoothstep(0.30, 0.85, n)`。
- Precious concentration：`smoothstep(0.60, 0.92, n)`。

没有 per-cell random，也没有 per-world min/max normalization。固定世界中矿化区跨多个相邻 Cell 连续分布；Precious 的中位数为 0，显著比 Base Metal 稀疏，且两个 channel 不相同。

## Pipeline 与 Debug

正式调用顺序扩展为：

```text
Terrain → Climate → Hydrology → Geology → Surface Water → Ecology → Soil
                                                                    ↓
                                                   Natural Resource Potential
```

统一 World Generation Debug 新增 `Resources` Page，页内八个数字 View 对应八类 Potential，均使用固定 `[0,1]` 连续 heatmap。没有新增全局快捷键。Cell Inspector 展示八个最终值，并按当前 View 重算少量解释字段（Soil Quality、Temperature/Water/Terrain Suitability、Biome factor、Host、Concentration、River/Lake/Coastal/Estuary contribution 等）；中间量没有写入正式 Layer。
