## 正式语义

`background_arcane_potential` 表示当地天然具有多强的、让 Mana 转化为持续魔法效应的潜在能力。它是一个与 Cell 对齐、值域为 `[0, 1]` 的天然背景连续场，不描述当前 Mana 数量、当前魔法化程度、Leyline 强度、Mana 流动或稳定度，也不是自然资源或生态适宜度。

该字段与 `background_mana`、`background_stability` 处于同一生成阶段和抽象层级，因此正式归入 `ArcaneFieldLayer`。本版本的 Layer 只包含这三个背景连续场，没有增加其他正式字段。

## 自然地理独立性

`ArcaneFieldGenerator` 的正式输入保持为 `SpatialGraph`、`world_seed` 与 `ArcaneFieldSettings`。Potential 只读取 `graph.cell_centers[cell_id]`，不读取 Terrain、Climate、Hydrology、Geology、Surface Water、Ecology、Soil 或 Resource Potential。

Arcane Field targeted test 使用相同 World Seed 与 SpatialGraph 分别生成 Continents 和 Archipelago 自然地理结果；两份自然地理数据不同，但 `background_arcane_potential` 完全一致。Generator 不接收 Template 或任何自然地理 Layer，且测试确认生成前后 SpatialGraph 的 Cell centers 与邻接拓扑不变。

## Seed Domain 与生成算法

Potential 使用独立 salt：

```text
ARCANE_POTENTIAL_SEED_SALT = 0x504F544C  # POTL
seed = DeterministicRng.stable_mix(world_seed, ARCANE_POTENTIAL_SEED_SALT)
```

Noise 配置：

| 参数 | 值 |
|---|---:|
| Noise Type | `TYPE_SIMPLEX_SMOOTH` |
| Fractal Type | `FRACTAL_FBM` |
| Octaves | 3 |
| Lacunarity | 2.0 |
| Gain | 0.40 |
| Weighted Strength | 0.0 |
| Domain Warp | disabled |
| Feature Scale | 1000 world units |
| Frequency | 0.001 |

每个 Cell 只在其 world-space center 采样一次 Potential Noise。原始值使用固定映射：

```text
value = clamp((raw_noise + 1.0) * 0.5, 0.0, 1.0)
```

没有使用二维临时纹理、graph propagation、分位数归一化、per-world min/max normalization 或任何额外分布变换。Potential 不由 Mana 或 Stability 推导；修改 `potential_feature_scale` 的测试确认只改变 Potential 空间结构，不改变已有两个背景场。

## Arcane Field Tests

`arcane_field_generator_test.gd` 的 8 个 test groups 全部通过，覆盖：

- 三个字段的 Cell 对齐长度、finite 与 `[0, 1]` 值域；
- Settings 默认值、复制与非法 scale validation；
- 相同输入完全确定、不同 World Seed 改变 Potential；
- `POTL` 独立 seed domain 与 direct world-space sample；
- Potential 不与 Mana 或 Stability 完全相同；
- 固定 FastNoiseLite 配置与固定数值映射；
- 修改 Potential feature scale 改变空间结构且不改变 Mana/Stability；
- 三个字段的空间连续性与跨 resolution 同坐标一致性；
- SpatialGraph preservation 与 Template independence。
