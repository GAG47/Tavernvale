# v3.0.1.2 — Province & Bottom Refactor

## Scope

The former Province generation components followed the final Land/Ocean coastline. A nearby
island separated by even one submerged Cell therefore received an independent Province seed,
which could cascade into a one-Cell Province and Rock Region. Province generation now uses a
generation-only **Continental Province Support** mask: `continental_value >= 14`. Connected
support is graph-native and may cross submerged Cells. Seeds and seed count still use only true
Land Cells (`terrain_height >= 0`); a support component with no Land remains Oceanic Crust.

Submerged support is only a neutral propagation bridge. Graph distance and deterministic edge
variation remain active, while Province-specific terrain suitability does not apply underwater.
The existing priors, local suitability, target 800 Cells per Province seed, and maximum 32 seeds
were not changed. Cells below support threshold always remain Oceanic Crust; Ocean Cells inside
a land-backed support component may now carry a continental Province.

## Rock sequence and BOTTOM

Deep Substrate and the separate Continental/Oceanic basement decision have been removed. They
were a second macro-classification that took control after the Province-specific transition
sequence had already reached BOTTOM. `RockLayerRules.sequence_for()` now owns the complete
sequence: it follows the unchanged non-BOTTOM transition graph, then continues the same
deterministic RNG stream to choose one equally weighted terminal Rock from Gneiss, Schist,
Diorite, Granite, or Gabbro. Adjacent equal Rocks are stored once. The final Rock is terminal and
extends to `-INF`; all preceding Rocks retain the existing finite thickness rules.

No Rock catalog/property, Province prior, Province/Rock Region target size, thickness parameter,
Groundwater/Aquifer rule, Soil mapping, Resource weight, or Arcane weight was changed.

## Verification

Dedicated Geology, Subsurface Strata, Groundwater, Hydrology, Soil, Ecology, Resource Potential,
and Arcane tests passed. All 26 worldgen `*_test.gd` scripts passed. The 20,000-Cell Debug scene
also ran headless for 20 seconds without script errors. Fixed pipeline hashes were updated only
after confirming the expected Province/RockType propagation.

Compared with v3.0.1.1, the coastline no longer defines Province generation components, and the
Rock Sequence itself now includes its unified terminal BOTTOM Rock; no Deep Substrate system or
compatibility API remains in current code, tests, or Debug.
