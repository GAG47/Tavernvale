## 目标

在 projected terrain 之后生成一套 deterministic、空间连续且受地形弱引导的 Geology 基底，正式提供 Province、Dominant Material、Permeability 和 Erodibility；只将 Erodibility 接入现有 Hydrology Conditioning 的 Least-Cost Breach cost，不引入板块、地质年代、Soil、地下水或资源系统。

- 新增正式 `GeologyLayer`，包含 `province_id`、`material_id`、`permeability`、`erodibility`。
- 新增固定的 6 类 Province、7 类 Material、Province → Material 权重和 Material → Physical Properties lookup。
- 新增 `GeologyGenerator`，使用 projected terrain suitability、有限 seeds 和两级 multi-source graph expansion。
- 新增 `GeologyValidator`，检查数组长度、ID、Oceanic Crust、物性范围和 lookup 一致性。
- Pipeline 调整为 Projected Terrain → Geology → Preliminary Climate → Preliminary Flow → Conditioning → Final Climate → Formal Hydrology。
- Hydrology Conditioning 新增 Geology 输入，material resistance 只乘在原 cut requirement 上。
- Debug 新增 Province、Material、Permeability、Erodibility 四个模式、统计和 Cell Inspect。
- 新增 Geology 人工图测试，并扩展 Conditioner 的 material cost 测试。

## 关键实现

### Province Suitability

Ocean Cell 直接设置为 Oceanic Crust，不参与陆地竞争。陆地 suitability 使用 projected terrain 的弱引导：

- Craton：偏好较深内陆、低 relief、较低高度。
- Orogenic Belt：偏好较高高度、高 relief 和一定内陆性。
- Sedimentary Basin：偏好内陆、平缓、较低高度及相对邻域低地。
- Passive Margin：偏好近海、平缓及低到中等高度。
- Volcanic Province：偏好 Orogenic suitability、高地与近海；seed 配额和扩展阻力共同限制面积。

Coast distance 使用 Spatial Graph 上从临海 Land Cell 开始的多源 BFS。Local relief、neighbor mean、normalized height 和 coast distance 都只形成连续 suitability cost，不把 Province 与某个 terrain threshold 做一对一硬分类。

### Province Seeds 与扩展

- 每个陆地连通块至少一个 Province seed。
- 目标尺度为约 `800 Cells / seed`，每个连通块上限 32 seeds。
- 固定 seed 类型周期为 Craton 30%、Orogenic 25%、Sedimentary 25%、Passive Margin 15%、Volcanic 5%；小于一个 seed 尺度的陆块选择平均 suitability 最高的大陆 Province，并降低 Volcanic 的单-seed 竞争权重。
- seed Cell 由 suitability、与既有 seeds 的空间分离度和 salted deterministic variation 共同选择。
- 使用 graph distance、目标 Province suitability 和小幅 deterministic edge variation 做 multi-source cost expansion。
- Volcanic expansion cost 额外乘 1.60，使其保持为有限的小型 Province，而不是覆盖其他大陆 Province。
- 海洋隔离的小岛独立获得 seed，不会出现未赋值区域。

固定 Debug 世界共使用 28 个 Province seeds。

### Material Patches

- 按相同 Province 的连通块处理，Patch 不跨 Province 边界，也不会跨 Ocean/Land 边界。
- 目标尺度为约 `180 Cells / material seed`，每个 Province 连通块上限 96 seeds。
- Material seed 通过 deterministic farthest-point selection 分散布置。
- 每个 seed 使用 `GeologyCatalog.material_weights()` 的固定 Province 权重抽取 Material。
- Material seeds 再以 graph distance 和轻微 deterministic edge variation 做 multi-source expansion。
- 固定 Debug 世界共使用 145 个 Material patch seeds。

Province → Material 权重及 Material → permeability / erodibility lookup 均集中在 `GeologyCatalog`。物性完全由 Material 固定 lookup，没有每 Cell 随机 variation。

### Hydrology Conditioning

使用固定温和阻力范围：

```text
material_resistance = lerp(1.50, 0.75, erodibility)
material_adjusted_cut_cost = original_cut_cost × material_resistance
```

仅 `_least_cost_breach` 对需要削低 Neighbor 的原 cut requirement 乘以 material resistance。Priority-Flood、small Fill、fallback Fill、inflow gate、max distance、max cost、planned channel height、`_apply_breach` 和实际 carve depth 均未修改。Permeability 没有被 runoff、Flow Accumulation、River 或其他 Hydrology 算法消费。

### Debug

- `G`：Geologic Province，固定分类颜色和每类 Count / %。
- `M`：Dominant Material，固定分类颜色和每类 Count / %。
- `K`：Permeability，低到高连续色阶及 Min / Max / Mean。
- `E`：Erodibility，难侵蚀到易侵蚀连续色阶及 Min / Max / Mean。
- Geology Inspect：Projected Height、Province、Material、Permeability、Erodibility。
- Conditioning Inspect：新增 Material、Erodibility、Material Resistance；原统计继续保留。

## 测试

新增/扩展的人工图覆盖：

1. 同 Seed + 同 Terrain 完全 deterministic。
2. 四个正式数组长度等于 Cell Count。
3. permeability / erodibility 始终位于 `[0, 1]`。
4. Ocean Cell 全部为 Oceanic Crust。
5. 七类 Material lookup 与推荐值一致，六类 Province 权重和为 1 且不是一对一映射。
6. Province region growing 在线形图中形成大区间，无 1~2 Cell 默认碎片。
7. Material patch expansion 在线形图中形成中尺度区间，无逐 Cell 抽签。
8. 相同地形的双 Breach 路径优先选择高 erodibility Material。
9. 低 inflow 即使为 Shale / Mudstone 也不能绕过 inflow gate。
10. 高 inflow + Crystalline Rock adjusted cost 超过上限时仍不得 Breach。
