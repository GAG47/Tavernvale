# v3.0.3.1 — Tectonic Plate Foundation

## Goal and scope

This version adds a deterministic, large-scale Tectonic Plate foundation over the existing
SpatialGraph, World Composition, and final Terrain. It partitions every Cell into one of five
connected plates and assigns one two-dimensional velocity to each plate. Existing broad highlands,
uplift, and relief influence partition cost and can softly constrain relative plate velocity.

This phase does not feed tectonics back into Terrain and does not classify boundaries or generate
uplift, rifts, trenches, volcanoes, magma, geothermal behavior, groundwater, or resources.

## Formal interface

`TectonicPlateLayer` stores only `PackedInt32Array plate_id` and
`PackedVector2Array plate_velocity`. It exposes Cell/plate counts and safe ID/velocity queries.
Anchors, smoothed height fields, terrain structure, accumulated partition distance, and boundary
statistics remain generation diagnostics and are not formal Layer data.

## Algorithm and locked defaults

Macro and regional height are independently smoothed from formal `terrain_height`, using inverse
edge-distance neighbor weighting and synchronous 50/50 current/neighbor updates. With radii 80
and 200 and standard spacing, the standard world uses 8 and 20 passes. Terrain structure follows
the specified smoothstep highland, relative uplift, and normalized macro-relief terms and the
specified multiplicative merge.

Five anchors are selected with an isolated RNG derived from the world seed and plate salt. Each
selection draws 96 distinct candidates, applies the specified anchor weight and initial 0.45
reference-spacing factor, permits four 0.85 spacing relaxations, and uses deterministic farthest
fallback only if no sampled candidate succeeds. Map edges receive no special treatment.

Plate partition uses multi-source Dijkstra with exact edge cost
`distance * (1 + 2.5 * mean_structure)` and exact ties favor the lower plate ID. Initial velocity
angles and speeds use independent deterministic salts and the locked 0.8–1.2 speed range. Boundary
edges with mean structure at least 0.35 are accumulated by ordered plate pair using squared
structure weight. Six synchronous relaxation rounds use target convergence 0.50 and correction
factor 0.25, then clamp speeds to 0.75–1.25.

All other defaults are exactly those specified in the v3.0.3.1 design; no parameter was tuned from
the generated result.

## Debug

The existing World Generation Debug now has a Tectonics page with continuous Terrain Structure,
Tectonic Plates, Plate Anchors, and Plate Velocity views. Plate colors are stable by plate ID.
Anchors are ring markers backed only by generation diagnostics. Velocity arrows originate near
each plate's mean in-window Cell position and scale with speed. Cell inspection includes Cell ID,
terrain height, continental value, terrain structure, plate ID, and velocity.

## Known limitations

The five plates describe only the current map window; edge-truncated plates and anchors are valid.
The model does not reconstruct geologic history, does not require every strong terrain feature to
be a plate boundary, and allows boundaries through ordinary land or ocean. Visual calibration can
be reviewed in the new Debug page later, but this implementation identifies no mandatory parameter
change and retains every locked default.
