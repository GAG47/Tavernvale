# v1.9.1 Ecology Slope Reference Correction

- Version: v1.9.1
- Date: 2026-08-30
- Commit: 未提交

## 目标

只将 Ecology 的默认 `slope_reference` 从 `0.05` 调整为 `0.5`，使其与固定 Debug 世界约 `0.5` 的典型局部下降坡度处于同一尺度，缓解普通地形的 `slope_factor` 和 `drainage_index` 过早饱和。

## 修改内容

- `EcologySettings.slope_reference` 默认值由 `0.05` 改为 `0.5`。
- 未修改坡度计算、Drainage 公式、Closed Basin modifier 或任何其他 Ecology / 上游参数。
- 使用 Seed 1 / Continents / 2000 × 1000 / 20000 Cells 重新生成完整 Debug pipeline，仅评估 Drainage 结果。

## 修改文件

- `scripts/world/worldgen/ecology/ecology_settings.gd`
- `docs/logs/2026-08-30_v1.9.1_ecology-slope-reference.md`（新增；项目开发规则要求）

## 关键实现

唯一生产代码变化：

```gdscript
var slope_reference: float = 0.5
```

以下公式保持不变：

```text
slope_factor = slope / (slope + slope_reference)
surface_escape = slope_factor
Closed Basin: surface_escape *= 0.35
drainage = 1 - (1 - permeability) * (1 - surface_escape)
```

固定 Debug 世界的 terrestrial non-Lake Drainage：

| Statistic | Before (0.05) | After (0.5) |
| --- | ---: | ---: |
| Min | 0.120000 | 0.120000 |
| P25 | 0.869212 | 0.469380 |
| P50 | 0.936054 | 0.650046 |
| P75 | 0.969635 | 0.807343 |
| Max | 0.998909 | 0.989603 |
| Mean | 0.861424 | 0.621035 |

按局部下降坡度分组：

| Group | Cell Count | Before Mean | After Mean |
| --- | ---: | ---: | ---: |
| Near-flat slope `< 0.1` | 946 | 0.395489 | 0.324950 |
| Ordinary slope `0.1 ..< 1.0` | 5477 | 0.899879 | 0.594281 |
| Steep slope `>= 1.0` | 2048 | 0.973806 | 0.829350 |

Closed Basin 对照：

- 239 个 terrestrial non-Lake Closed Basin Cells 的实际平均 Drainage 为 `0.277711`。
- 将同一批 Cell 仅反事实移除 Closed Basin modifier 时，平均值为 `0.417601`。
- Basin 边界样本中，Basin Cell 平均为 `0.269662`，相邻开放陆地 Cell 平均为 `0.620992`。

图形 Debug 截图核验结果：

- 近乎平坦区域明显转为更暗的低 Drainage 色阶。
- 普通地形不再大面积挤在亮黄色高端，形成广泛的绿色 / 橄榄色中间范围。
- 陡坡和强地表出口区域仍保持明亮高 Drainage。
- Closed Basin 形成相对周边更暗的低 Drainage 局部斑块；数值边界对照与图面一致。

## 已知问题

- 本次只评估 Drainage；没有根据 Moisture、Vegetation 或 Biome 数量继续调参。
- Exactly-flat Cells 的 `slope_factor` 在两个参数下都为 0，因此其 Drainage 仍只由 permeability 决定；本次降低主要体现在具有小幅非零坡度的近乎平坦区域。
