## 关键实现

River Network 的语义是由正式上下游边连接的一整棵河系，包含主河和所有已达到阈值的支流。当前版本不拆分 individual River 或 River Segment。

在同一份固定世界上只改变 River Threshold：

- Seed：1
- Template：Continents
- Cell Count：20000
- Spatial、Composition、projected terrain、Preliminary Climate、Conditioning 结果完全复用

结果：

| Threshold | River Network Count | River Cell Count | Max Strahler Order | Largest Discharge |
| ---: | ---: | ---: | ---: | ---: |
| 5000 | 332 | 1252 | 3 | 123956.335938 |
| 10000 | 143 | 629 | 2 | 123956.335938 |
| 20000 | 65 | 276 | 2 | 123956.335938 |

选择 `5000.0`。它是三组中唯一达到目标 3–4 级范围的候选值，能够保留上游支流与汇流层级；1252 个 River Cell 占全部 20000 Cell 的约 6.26%，没有把大量普通 Cell 标记为河流。10000 与 20000 都只达到 Order 2，因此不采用“多个结果都合理时优先 10000”的次级规则。

阈值仍是固定累计 runoff 数值，没有绑定 P90、百分位数或 River Cell 比例。
