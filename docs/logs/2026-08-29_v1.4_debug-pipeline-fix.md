# v1.4 Debug Climate Pipeline Fix

- Version: v1.4 小修正
- Date: 2026-08-29
- Commit: 未提交

## 目标

修正现有 World Debug View 的阶段顺序，使 v1.3 Preliminary Climate 始终基于 v1.2 projected `terrain_height`，并为 Hydrology Conditioning 模式补充颜色图例。

## 修改内容

- 将 Debug 数据流调整为从同一份 projected terrain 分叉：Climate Generator 生成 Preliminary Climate；Hydrology Conditioner 独立生成 conditioned terrain。
- Temperature / Precipitation Debug 继续读取 Preliminary Climate，不在 Hydrology Conditioning 后重新运行 Climate Generator。
- Hydrology Conditioning Debug 统计下方增加 Fill、Carve、Closed Basin、未修改陆地和 Water 的文字图例。

## 修改文件

- `tests/worldgen/composition/world_composition_debug_view.gd`
- `docs/logs/2026-08-29_v1.4_debug-pipeline-fix.md`

## 关键实现

当前 Debug 流程为：

```text
projected terrain_height
├─> WorldClimateGenerator -> preliminary_climate
└─> HydrologyConditioner -> conditioned terrain_height
```

`terrain` 变量继续保存 conditioned terrain，供 Terrain、Land/Water 与 Hydrology Debug 使用；`climate` 变量保存由 projected terrain 生成的 v1.3 Preliminary Climate，供 Temperature 与 Precipitation Debug 使用。

图例只在 `D` Hydrology Conditioning 模式的统计区域显示，没有修改既有颜色。
