# World Natural Generation v1.0.1 / Spatial Topology Fix

- Version: World Natural Generation v1.0.1 / Spatial Topology Fix
- Date: 2026-08-26
- Commit: `47ec1ca`

## 目标

修复 v1.0 中最终 Neighbor 与真实 Voronoi 拓扑不一致，以及理论相同 Vertex 未可靠合并的问题；不改变 Spatial Skeleton 的主体设计。

## 修改内容

- Delaunay Neighbor 改为只在 Voronoi 构建期间使用的 Candidate Neighbor。
- 统一 Vertex 后建立 Edge Registry，并由有效 Shared Edge 生成 Final Neighbor 和 Neighbor Distance。
- Vertex Dedup 改为 Spatial Bucket、周围 8 Bucket 搜索和真实距离检查。
- 增强 Cell、Vertex、Edge、Neighbor 的拓扑 Validator。
- 增加 Border Neighbor、Vertex Dedup、Shared Edge 和点接触非邻接测试。
- 修复测试组数量输出，改为从实际 Callable 列表读取。
- Debug View 增加 Selected Cell 与 Neighbor 的 Shared Edge 高亮。

## 修改文件

- 修改当时位于 `world/worldgen/spatial/` 的 Geometry、Voronoi、Generator、Graph 和 Validator 脚本。
- 修改 `tests/worldgen/spatial/` 下的自动测试和 Debug View。

## 关键实现

- Edge 使用 `(min_vertex_id, max_vertex_id)` 规范化，登记使用它的一至两个 Cell。
- 只有被两个 Cell 使用且长度大于 `edge_epsilon` 的 Edge 才生成双向 Final Neighbor。
- 默认 1000 × 1000 世界的 `vertex_merge_epsilon` 和 `edge_epsilon` 均为 `0.001`。
- Half-Plane 计算改用以 Seed 中点为原点的等价形式，避免大平方坐标相减造成的浮点消减误差。
- 默认图的拓扑统计为 10000 Cells、20002 Vertices、30001 Edges、383 Border Cells。

## 测试

- 测试脚本包含 10 个实际测试组，成功输出按实际 Callable 数量生成。
- 覆盖原有 Spatial 测试以及 Border Neighbor、Shared Edge Vertex ID、Vertex/Cell 双向关系、点接触非邻接和 Candidate Edge 淘汰。
- `SpatialGenerator.generate()` 返回前运行包含新拓扑规则的 Validator。
- 本次 v0 目录迁移会再次运行该测试套件并在 v0 日志记录实测结果。

## 已知问题

- Spatial Skeleton 按设计仅支持有限矩形，不支持 World Wrap。
- 浮点拓扑使用与世界尺寸相关的 epsilon。

## 设计偏差

无。
