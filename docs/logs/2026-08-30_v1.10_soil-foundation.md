# v1.10 Soil Foundation

- Version: v1.10
- Date: 2026-08-30
- Commit: 未提交

## 目标

在 Final Terrain、Final Climate、Formal Hydrology、Geology、Surface Water 和 Ecology 之后新增独立 Soil 层，以固定语义的 CLORPT / SCORPAN-lite 与 Catena / Toposequence 关系推断每个 World Cell 的表层土壤状态。

本阶段只生成长期最终状态，不模拟真实成土时间积分、泥沙输运或侵蚀反馈；Soil 只消费上游最终数据，不反向重新生成 Ecology，也不计算农业潜力。

## 修改内容

- 新增 `SoilCatalog`、`SoilSettings`、`SoilLayer`、`SoilGenerator` 和 `SoilValidator`。
- 统一 Debug pipeline 在 Ecology 后生成并保存 `SoilLayer`。
- Final Pipeline 测试结果在 Ecology 后保存 Soil，并检查特殊地表和 Validator。
- World Debug 新增 Soil Depth、Soil Texture、Organic Matter 和 Soil Fertility 四个模式、Land-only 统计、Cell Inspect 以及 Material → Texture 控制台诊断。
- 新增 9 组 deterministic / semantic Soil 测试；未增加批量 Seed 测试。

## 正式接口与 Pipeline

`SoilLayer` 只保存四个正式数组：

- `soil_depth: PackedFloat32Array`，固定相对尺度 `[0, 1]`。
- `soil_texture_id: PackedInt32Array`。
- `organic_matter: PackedFloat32Array`，范围 `[0, 1]`。
- `soil_fertility: PackedFloat32Array`，范围 `[0, 1]`。

Texture enum 由粗到细为：

```text
NONE
SANDY
LOAMY
SILTY
CLAYEY
```

`ROCKY` 不是 Texture；未来以低 `soil_depth` 和 parent geology 共同表达裸岩。Marine、Lake 和 Glacier 的三个连续值固定为 0、Texture 为 `NONE`；Wetland 正常生成 Soil。

实际流程为：

```text
Projected Terrain
→ Geology
→ Preliminary Climate
→ Preliminary Flow
→ Hydrology Conditioning
→ Final Terrain
→ Final Climate
→ Formal Hydrology
→ Surface Water
→ Ecology
→ Soil
```

当前工程没有统一生产级 `WorldResult` 类，`WorldCompositionLayer` 仍是 v1.1 macro composition 专用层。因此 Soil 按现有架构保存在统一 Debug pipeline 的 `soil: SoilLayer`，并加入 Final Pipeline 测试结果 Dictionary；没有把 Soil 塞入早期 CompositionLayer。

| Shale / Mudstone | 0.80 | 0.75 | 0.65 |

## Terrain、Climate 与 Deposition 指标

Slope 直接复用 `EcologyGenerator.maximum_descending_slope()`，只考虑直接邻居中的真实下降坡度和正式 neighbor distance。Soil 使用自己的 `SoilSettings.slope_reference = 0.5`，没有读取或修改 Ecology 参数。

```text
slope_factor = slope / (slope + 0.5)

valley_position = clamp(
    (mean_neighbor_height - current_height)
    / (mean_abs_local_relief + epsilon),
    0,
    1
)

temperature_weathering = smoothstep(-10, 20, temperature)
precipitation_supply = precipitation / (precipitation + 10)
climate_weathering = temperature_weathering * precipitation_supply

formation_potential =
    weatherability * (0.35 + 0.65 * climate_weathering)

erosion_pressure =
    slope_factor * lerp(0.40, 1.00, erodibility)
```

Flow Strength 复用 Ecology 的正式 helper，并从 `WorldHydrologyLayer.settings.river_runoff_threshold` 读取 threshold；Soil 没有复制硬编码 river threshold。

```text
flow_strength = clamp(
    log(1 + accumulation / river_threshold) / log(21),
    0,
    1
)

deposition_tendency =
    (1 - slope_factor)
    * clamp(0.80 * valley_position + 0.20 * flow_strength, 0, 1)
```

Deposition 只表示长期局部沉积倾向；没有沿 `flow_to` 搬运泥沙，没有 sediment routing 或迭代。

## Soil Depth

v1.10 初版公式：

```text
soil_depth = clamp(
    0.15
    + 0.70 * formation_potential
    + 0.35 * deposition_tendency
    - 0.55 * erosion_pressure,
    0,
    1
)
```

该值是固定语义的相对深度，不表示米或厘米。没有使用当前世界 min/max、percentile 或 rank normalization。

## Soil Texture

```text
texture_fineness = clamp(
    parent_fineness
    + 0.10 * climate_weathering
    + 0.15 * deposition_tendency,
    0,
    1
)
```

分类阈值：

```text
fineness < 0.30          → SANDY
0.30 <= fineness < 0.60 → LOAMY
0.60 <= fineness < 0.78 → SILTY
fineness >= 0.78         → CLAYEY
```

Texture 同时受 parent material、轻量 weathering 和 deposition 影响，没有逐 Cell Noise 或随机 Soil seed。

## Organic Matter

```text
cold_retention = 1 - smoothstep(5, 30, temperature)
water_retention = 1 - drainage_index

organic_retention = clamp(
    0.30
    + 0.35 * cold_retention
    + 0.35 * water_retention,
    0,
    1
)

organic_matter = clamp(
    vegetation_potential * organic_retention,
    0,
    1
)
```

Wetland 没有固定 Organic bonus；低 Drainage 已经提供保存能力。

## Leaching 与 Soil Fertility

```text
leaching_temperature = smoothstep(15, 30, temperature)
leaching_moisture = smoothstep(0.45, 0.75, ecological_moisture)

leaching = clamp(
    leaching_temperature
    * leaching_moisture
    * drainage_index,
    0,
    1
)

soil_fertility = clamp(
    0.55 * parent_nutrient
    + 0.30 * organic_matter
    + 0.20 * deposition_tendency
    - 0.25 * leaching,
    0,
    1
)
```

Fertility 表示天然养分潜力，不乘农业温度、坡度或适耕性。

## Validator

`SoilValidator` 检查：

- 四个数组长度均等于 Cell Count。
- Depth、Organic Matter、Fertility 均 finite 且位于 `[0, 1]`。
- Texture ID 属于正式 enum。
- Marine、Lake、Glacier 的连续值为 0、Texture 为 `NONE`。
- 其他普通陆地（包括 Wetland）Texture 不能为 `NONE`。

Generator 也检查所有必需上游输入长度、finite/range、Spatial neighbor 与 distance，以及 Formal Hydrology settings。

## Debug

统一 `world_composition_debug_view.tscn` 新增：

- `S`：Soil Depth。
- `Shift+S`：Soil Texture。
- `U`：Organic Matter。
- `Shift+U`：Soil Fertility。

三个连续模式显示 soil-bearing Land-only 的 Min、Mean、P25、P50、P75、P90、Max。Texture 显示 Sandy / Loamy / Silty / Clayey 的 Land-only count 和百分比，并在控制台打印 Material → Texture 数量交叉诊断。

Cell Inspect 显示 Terrain Height、Geology Material、Biome、Soil Depth、Texture、Organic Matter 和 Fertility。原有 Soil Depth / Texture 地图、其他 World Debug 模式和快捷键保持不变。

## 测试

新增 9 组 Soil 测试覆盖：

1. 相同输入产生相同 Soil 输出。
2. Steep slope 比 flat terrain 更薄。
3. Valley 比 ridge 更厚。
4. Sandstone 倾向 Sandy。
5. Shale / Mudstone 倾向 Clayey。
6. 低 Drainage 保存更多 Organic Matter。
7. Warm + Wet + Well-drained 产生更高 Leaching。
8. 更高 Leaching 降低 Fertility。
9. Marine / Lake / Glacier 没有正式 Surface Soil，Wetland 正常生成 Soil。

## 已知问题与后续版本

- v1.10 初版 Soil Depth 的 Mean 约为 `0.204 ~ 0.214`、P50 约为 `0.159 ~ 0.166`，整体偏薄。
- v1.10.1 的 Debug 中间量诊断确认 Erosion 平均扣减几乎抵消 Formation 平均增益；后续在 v1.10.1 将 Depth erosion weight 从 `0.55` 单独校准为 `0.40`。
- v1.10.1 另增加了 Formation / Erosion / Deposition 与 deposition counterfactual 控制台诊断。这些后续改动不回写到本日志记录的 v1.10 初版公式。
- v1.10 按范围不处理农业潜力、pH、N/P/K、盐度、土层剖面、真实米制深度、泥沙输运、动态侵蚀、资源或 Soil ↔ Ecology 迭代。

## 设计偏差

当前工程没有独立的生产级 World aggregate result；Soil 按现有统一 Debug pipeline 和 Final Pipeline 测试结构正式接入，没有为单一版本额外创建复杂聚合架构。除此之外无设计偏差。
