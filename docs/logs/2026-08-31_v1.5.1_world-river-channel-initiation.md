# v1.5.1 World River Channel Initiation

- Version: v1.5.1
- Date: 2026-08-31
- Commit: 未提交

## 目标

在不改变 runoff、`flow_to`、Flow Accumulation、Watershed、Preliminary Flow 或 Hydrology Conditioning 的前提下，让正式 World River 更早沿现有排水路径出现，同时过滤不适合作为世界尺度正式河流的 1～2 Cell creek。

## 修改内容

- Formal Hydrology 默认 `river_runoff_threshold` 从 `5000.0` 改为 `3000.0`。
- 新增 `formal_river_min_cells = 3`。
- 先按 3000 构建完整候选 River Network；再过滤少于 3 Cell 的候选网络，并从过滤后的 mask 重新计算正式 Strahler Order、`river_network_id` 和 `HydrologyRiverNetwork`。
- 被过滤 creek 的 `local_runoff`、`flow_to`、`flow_accumulation` 和 `watershed_id` 保持不变。
- Ecology 与 Soil 继续直接使用 `flow_accumulation` 和正式 Hydrology settings 中的 3000 threshold 连续计算水文影响，不依赖正式 River Network 身份。
- World Debug 控制台增加正式最小长度、精确 2 Cell 数、长度 P75/P90、4+/8+/16+ 比例以及短河成因诊断；未增加 HUD。

Hydrology Conditioning 的独立 `breach_min_inflow = 5000.0` 未修改。
