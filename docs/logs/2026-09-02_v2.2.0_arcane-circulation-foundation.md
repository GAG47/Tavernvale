## 阶段职责

v2.2 在冻结的 v2.1 Arcane Web 几何骨架上生成长期稳定的有向魔力循环。它回答“魔力在现有 Leyline 上长期如何流动”，不重新采样 Nucleus、不修改 Power Diagram、不改变 Node、Edge、Domain、ID 或拓扑。

本阶段不引入 Source、Sink、Arcane Coupling、Nexus Strength、Spell/Ecology/Resource effects，也不恢复 Structural Importance、Betweenness 或人工 Major Leyline。

## 正式数据

新增 `ArcaneCirculationLayer`，唯一正式数据字段为：

- `edge_flow: PackedFloat32Array`

`edge_flow[i]` 严格对应 `ArcaneWebLayer.edges[i]`。正值沿正式 canonical 方向 `node_a_id -> node_b_id`，负值沿反方向；`abs(edge_flow)` 是长期平均 Mana Flow 强度。Flow 不写回或复制 `ArcaneWebEdge`。

## Cell Cycle Superposition

每个 visible `ArcaneWebDomain` 在内部计算一个 signed circulation potential。该值不保存到 Domain；Domain 仍然只是 Power Diagram 几何生成、查询与环流计算辅助结构，不代表具有不同魔法性质的世界板块。

Circulation potential 使用：

- stable seed domain salt：`0x43495243`（`CIRC`）
- FastNoiseLite `Simplex Smooth`
- FBM
- world-space scale：`700.0`，frequency：`1.0 / 700.0`
- octaves：`3`
- lacunarity：`2.0`
- gain：`0.50`
- sampling position：`domain.nucleus_position`

直接使用原始 `[-1, 1]` noise；没有 per-world min/max normalization。

对于每条 Edge，在 midpoint 按 weighted power distance 找到最接近的两个 Domain，再沿 `node_a -> node_b` 的左、右法线做稳定 epsilon probe，结合 Domain polygon containment 判定 left/right。极短边 probe 接近顶点时，使用同一 probe 的 power-distance 关系消除 epsilon 歧义，不使用 Domain ID 或 Nucleus 顺序决定方向。

正式公式为：

```text
edge_flow = left_domain.circulation_potential
          - right_domain.circulation_potential
```

该构造等价于相邻 Cell 闭合环流贡献的叠加；共享边界上的贡献自然加强或抵消。

## Conservation 与边界

内部 Junction 按 incident Edge canonical 方向累计 signed flow，使用明确 epsilon `1e-5` 验证 `abs(net_flow)`。Seed 1：

- Junction conservation error mean：`0.00000000666631`
- Junction conservation error max：`0.00000002980232`

Boundary Exit 表示更大 Arcane Web 被当前正式世界窗口裁切的位置，不要求净流量为零。Seed 1 同时存在自然 inflow 与 outflow，两者仅是窗口边界统计，不定义 Source/Sink。
