# v3.0.1.1 — RockType & Strata Refactor

## 目标与边界

本次重构删除旧的 7 类 `GeologyCatalog.MaterialType`，不保留兼容层。正式地质关系改为
Province → generation-only Rock Region → TFC-style Rock Sequence → coherent layer thickness →
Subsurface Strata。没有新增板块、断层、褶皱、侵入体、地质年代、孔隙率、矿床、洞穴、
Rock Region Layer 或 Deep Substrate Layer，也没有调节 Groundwater / Aquifer 参数。

## 正式结构

- `GeologyCatalog` 仅保留 6 种 Province。
- `RockCatalog` 保存 21 种具体 `RockType`，并提供固定 category、igneous composition、
  permeability、erodibility、rock strength、karst capability 与显示名称。
- `GeologyLayer` 保存 `province_id / rock_type_id / permeability / erodibility`；后两个数组是
  `RockCatalog` 查询结果的缓存，Validator 会检查一致性。
- `RockRegionAssigner` 按同 Province 连通区复用原 Material Patch 的分散 seed 与
  multi-source expansion 空间算法，尺度仍为每 seed 180 Cells、每 component 最多 96 seeds。
  返回的 seed Cell 仅供生成使用，不进入正式 World Fact。
- `RockLayerRules` 保存固定 Province root pool、完整 transition graph、RSEQ 随机域和
  basement pool。完整 sequence 按 world seed + Rock Region seed 生成，同 Region 共用。
- `SubsurfaceStrataLayer` 继续使用 CSR-like `cell_offsets / rock_type_ids / top_z`，查询接口改为
  `rock_type_at_z`，无岩石值改为 `NO_ROCK`。内部边界仍属于下一层，末层延伸至 `-INF`。

Transition graph 自身终止于 `BOTTOM`，已删除 `max_layers`、SQ00–SQ02 与 TH00–TH02。
规则验证会检查所有 root 可终止、无非 BOTTOM cycle，以及全部 RockType / next node 合法。
逻辑序列出现相邻相同 RockType 时，写入 CSR 前合并；basement 与上一层相同时，上一层直接
成为 `-INF` 终端层。

## Thickness 与 Deep Substrate

Province base thickness、`[0.75, 1.25]` noise factor、`[12, 55]` clamp 和
`min(1 + 0.1 * layer_index, 1.2)` depth factor 保持不变。厚度改为一张
SIMPLEX_SMOOTH + FBM world-space coherent noise，每个 logical layer 使用仅由稳定 seed 和
layer index 决定的 world-space offset；没有 per-cell random 或 per-world normalization。

Deep Substrate 继续使用原 DCRU noise、feature scale、amplitude、threshold 和
`continental_value + deep_noise * amplitude`。Continental basement 从
`GNEISS / SCHIST / DIORITE / GRANITE / GABBRO` 等权选择；Oceanic basement 固定为 GABBRO。
Deep Substrate 只决定 BOTTOM 对应的 basement，不改变前序 Rock Sequence。

## 消费者迁移

Groundwater 改为通过 `rock_type_at_z` 和 `RockCatalog.permeability_for` 查询；供水、水位、
盐度、active groundwater、Aquifer yield、0.18 / 0.45 阈值均未修改。Resource Potential 的
Construction Stone 直接使用 rock strength × exposure；Base Metal 与 Precious Mineral 按
规定 RockCategory factor 映射。Arcane Material 使用与 Base Metal 相同的 RockCategory
factor，其余魔法资源逻辑不变。

Soil 保留原 parent fineness / weatherability / nutrient 公式，将具体 RockType 机械映射到原有
岩性家族：侵入岩、喷出岩、砂质岩、泥质岩、碳酸盐/硅质沉积岩与变质岩。Hydrology、
Ecology、Surface Water 继续消费 Geology 的 permeability / erodibility 缓存，没有改写公式。
Debug 的旧 Material 视图已迁移为 21 种固定颜色的 Surface / Strata RockType 视图。

## 测试

`*_test.gd` scripts，全部通过。
