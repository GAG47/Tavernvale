## Manifestation 正式命名

v2.4.1 将两个过于具体、容易被理解为已经生成具体内容的 Manifestation 名称改为表达环境中主导作用方向的正式名称。Numeric values 保持不变，也没有保留旧 alias 或 compatibility constant：

| Value | Manifestation Type | 正式语义 |
|---:|---|---|
| 0 | `NONE` | 当前 Mana 不足以形成明显、持续的魔力环境表现。 |
| 1 | `MANA_DOMINANT` | Mana 已足够明显，但 Background Arcane Potential 较低；Mana 主要直接塑造当地环境，而非主要通过改变自然生态系统表现。该标签不表示已经产生具体物体或资源。 |
| 2 | `ECOLOGY_DOMINANT` | Mana 已足够明显且 Background Arcane Potential 很高；Mana 主要通过持续改造自然生态系统表现。本阶段只输出分类。 |
| 3 | `MIXED` | Mana 直接塑造环境与生态系统受 Mana 改造两方面都具有明显意义。 |

Arcane Ecology State 的 `NORMAL / INFLUENCED / DOMINANT` 语义及 numeric values 保持不变。

## 新 Thresholds

Settings 默认值正式调整为：

| Axis | LOW | MEDIUM | HIGH |
|---|---|---|---|
| Mana Concentration | `< 0.60` | `0.60 <= value < 0.75` | `>= 0.75` |
| Background Arcane Potential | `< 0.55` | `0.55 <= value < 0.65` | `>= 0.65` |

Mana medium threshold 保持 `0.60`；Mana high threshold 提高到 `0.75`。Potential thresholds 调整为 `0.55 / 0.65`。分类仍只使用四个固定绝对阈值，没有增加公式、变量或按世界归一化。
