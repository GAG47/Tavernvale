# v1.9.5 Ecological Moisture Water Balance

- Version: v1.9.5
- Date: 2026-08-31
- Commit: 未提交

## 目标

将 Ecological Moisture 的基础项从“先归一化供水、再永久乘法扣减”的模型改为简化的供水 / 需求平衡。高 Drainage 与高 Evaporation 现在提高达到同一湿度所需的降水量，但不再形成固定的 high-moisture ceiling。

## 正式公式

旧公式：

```text
climate_supply = precipitation / (precipitation + precip_reference)
base_retention = climate_supply
    * (1 - drainage_weight * drainage_index)
    * (1 - evaporation_weight * evaporation_factor)
```

新公式：

```text
retained_supply = max(
    precipitation * (1 - drainage_weight * drainage_index),
    0
)
drying_demand = precip_reference
    * (1 + evaporation_weight * evaporation_factor)
base_moisture = clamp(
    retained_supply / max(retained_supply + drying_demand, epsilon),
    0,
    1
)
ecological_moisture = clamp(
    base_moisture + river_bonus + lake_shore_bonus,
    0,
    1
)
```

`precip_reference = 10`、Drainage、Evaporation factor、River Bonus、Lake Shore Bonus、所有 Biome / Wetland thresholds 均保持不变。

没有修改 Climate、Hydrology、Surface Water、Drainage、River / Lake bonus、Soil 公式或参数，也没有修改 `.53` Wet threshold、Wetland 条件、Temperature bands 或 Biome Matrix。新基础公式随 precipitation 增大渐近于 1，不存在旧模型的固定 high-moisture ceiling。
