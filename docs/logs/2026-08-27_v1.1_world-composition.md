# Tavernvale v1.1 World Composition / 大陆构图

- Version: v1.1
- Date: 2026-08-27
- Commit: 64e0f35

## 目标

在 v1.0 Spatial Skeleton 之上生成一张确定性的、连续的宏观大陆构图值场。v1.1 只负责 World Composition，不生成物理 Height、最终 Sea Level、正式 Land/Ocean、continent_id 或任何后续地质和气候数据。

## v1.1 的职责与 continental_value

`WorldCompositionLayer.continental_value` 是与 Stable Cell ID 一一对应的 `PackedInt32Array`，范围为整数 0..100。数值表示 Cell 成为宏观大陆主体的倾向；它不是物理海拔。

本阶段直接采用 Azgaar-style Heightmap 运算，是因为 Hill、Pit、Range、Trough、Strait、Multiply、Smooth、Mask 及其有序模板已经形成一套可验证的宏观构图方法。v1.1 在算法内部直接将 `continental_value` 当作这些 primitive 的 height 数组，不再增加 score 到 potential 一类中间映射。

数值 `20` 的唯一含义是 `COMPOSITION_LAND_REFERENCE`：Debug 和 Azgaar `land` 范围操作使用它观察宏观大陆轮廓。它不是 Tavernvale 的最终 Sea Level，也不会生成正式 Land/Ocean 数据。

本阶段没有 `continent_id`，因为模板生成的是一张全局连续值场，而不是大陆所有权分配。连通块、命名、Anchor 和 ownership 均不属于 v1.1。

## 关键实现

### Composition RNG

Composition 使用独立的 31-bit LCG，并以 World Seed、Composition 专用 salt 和 `template_id` 生成流 seed。它不读取或写入 Godot 全局随机状态，也不复用 Spatial RNG。

### Uint8 数值行为

所有 primitive 写入值场时统一先 clamp 到 0..100，再用 `int` 截断非负小数。测试明确覆盖 `73.9 -> 73`、`1.9 -> 1`、`0.9 -> 0`，没有使用 `roundi()`。

### Primitive

- Hill：每个实例使用独立 `change` 数组和 FIFO 邻接传播；`change == 0` 可被其他 parent 再次尝试，结束后统一叠加回值场。
- Pit：每个实例使用独立 `used` 和共享、逐 queue item 衰减的 `h`；start 不预先标记，不复用 Hill。
- Range：以未访问邻居构造 15% wandering path，再执行横向扩散和每六个 path Cell 一次的 prominence。
- Trough：使用独立的 20% wandering path、较宽 endpoint 距离上限、减值扩散和相同 prominence。
- Strait：主路径不使用 visited；宽度处理保留持续累积的 `query`、`used` 和指数削减。加入任务允许的纯 step guard，仅在异常循环时报告失败。
- Multiply：只实现 `factor land`，围绕 Composition Reference 20 缩放。
- Smooth：从完整旧数组同时计算自己与邻居的均值，不在遍历中污染输入。
- Mask：使用 Cell Center 的归一化矩形边缘函数，支持正负 power 行为。

## Templates

Continents 共 15 个 Operation，顺序为：3 Hill、Multiply、Hill、3 Range、2 Strait、Smooth、2 Trough、Pit、Mask。每项参数与指定 Azgaar Continents script 一致。

Pangea 共 10 个 Operation，顺序为：5 Hill、Smooth、Multiply、2 Trough、Range。每项参数与指定 Azgaar Pangea script 一致。

Generator 严格按数组顺序执行，不重新排序。

## Azgaar Source Fidelity Check

2026-08-27 交叉核对了 Azgaar/Fantasy-Map-Generator 当前 `master`：

- `src/generators/heightmap-generator.ts`
- `src/data/heightmap-templates.ts`
- `src/utils/probabilityUtils.ts`
- `src/utils/numberUtils.ts`

逐项结果：

- Hill：一致。change-array、start 重试、FIFO、blobPower 和随机乘数一致。
- Pit：一致。独立 used、shared h、start 未预标记和邻居减值一致。
- Range：一致。未访问邻居 wandering、15% bias、横向扩散、linePower 和 prominence 一致。
- Trough：一致。land-reference start 重试、20% bias、距离上限、减值扩散和 prominence 一致。
- Strait：一致。无 visited 主路径、20% bias、`cellsX / 3` width cap、累计 query 和指数行为均保留。源码中幂写入后的 `>100 -> 5` 分支在 0..100 输入和小于 1 的正指数下不可达，因此无需额外写回。
- Multiply：一致。`land` 使用 20..100，并执行 `(value - 20) * factor + 20`。
- Smooth：一致。TypedArray map 的旧数组同时计算语义已显式实现。
- Mask：一致。归一化坐标、distance、反转和 factor 混合一致。
- Templates：Continents 与 Pangea 的 operation、参数和顺序一致。

Tavernvale 使用自己的确定性 RNG，因此不追求与 Azgaar Alea 的逐随机样本一致；要求的 primitive 规则与概率保持一致。

## Tavernvale SpatialGraph 必要适配

- `grid.cells.c[cell]` 翻译为 `SpatialGraph.cell_neighbors[cell]`。
- `grid.points[cell]` 翻译为 `SpatialGraph.cell_centers[cell]`。
- `findGridCell(x, y)` 翻译为对 Stable Cell ID 扫描并选择平方距离最近的 Cell。
- `Uint8Array` 翻译为 `PackedInt32Array` 加统一 clamp/truncate helper。
- Azgaar `cellsX` 翻译为 SpatialGraph 的 `columns`。

这些适配未修改 SpatialGraph，也未将传播或 wandering path 替换成最短路算法。

```bash

```
