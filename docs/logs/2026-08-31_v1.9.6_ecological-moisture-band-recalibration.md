# v1.9.6 Ecological Moisture Band Recalibration

- Version: v1.9.6
- Date: 2026-08-31
- Commit: 未提交

## 目标

在不修改 v1.9.5 Ecological Moisture 连续值、水文、土壤、Wetland 或 Biome Matrix 的前提下，移除旧公式时期遗留的 `.53` 通用 Wet 分界，为 Supply / Demand Water Balance 重新建立具有明确语义的 Moisture Band。

## 正式 Moisture Band

```text
Arid      moisture < 0.15
Dry       0.15 <= moisture < 0.30
Moderate  0.30 <= moisture < 0.50
Humid     0.50 <= moisture < 0.67
Wet       moisture >= 0.67
```

仅 `EcologyCatalog.moisture_band()` 的 Humid / Wet 边界由 `.53` 改为 `.67`。Temperature Band、Biome Matrix 和独立的 `wetland_moisture_threshold = .53` 均保持不变。

## 不变性

- 四模板 Ecological Moisture 的 Mean、所有分位数、Max 与 v1.9.5 逐项一致。
- Drainage、River / Lake influence 与 `wetland_moisture_threshold = .53` 未改。
- Soil Depth、Organic Matter、Fertility 与 v1.9.5 逐项一致。
- 未增加 Rainforest 专用、percentile-based 或 per-template threshold。
