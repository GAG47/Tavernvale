# Tavernvale v1.1.3 — Cleanup / Stability Fix

- Version: v1.1.3
- Date: 2026-08-27
- Commit: 65d4a27

## 目标

完成 v1.1 系列的配置与 Debug Renderer 收尾：禁止会产生规则共圆格点的 `jitter=0` 配置，修复 Composition Debug View 的 polygon triangulation 报错，整理已完成版本的日志 SHA，并执行基础回归。本次不修改 Shared Voronoi Topology、Boundary Seed、Delaunay、Composition 数据或六模板。

## 修改内容

- `SpatialConfig.validate()` 的 jitter 合法范围由 `[0, 1]` 改为 `(0, 1]`，默认值继续为 `0.9`。
- Spatial 测试删除把 `jitter=0` 当作合法格点配置的测试，改为覆盖默认值、极小正数、零、负数和大于 1 的校验边界。
- Spatial 与 Composition Debug Inspector 的导出范围同步排除零值，避免编辑器生成已知非法配置。
- Composition Debug Cell 填充从完整 Polygon 的 `draw_colored_polygon()` 改为基于 Cell Center 与有序 `cell_vertex_ids` 的 Triangle Fan。
- 每个显示三角形使用 `(center, vertex[i], vertex[i+1])`，最后自动闭合到 first vertex；世界空间面积小于现有 geometry epsilon 的三角形只在显示层跳过。
- Triangle Fan 使用 `draw_primitive()` 直接提交三角形，避免 Godot 再次调用 polygon triangulator；没有修改 `cell_polygons`、Vertex、Edge 或 Composition Layer。

## 关键实现

### jitter 配置边界

`jitter <= 0.0` 与 `jitter > 1.0` 都会返回配置错误 `jitter must be in the range (0, 1]`。Generator 原有的 config validation 会拒绝该配置，不为规则网格增加任何 Delaunay/Voronoi fallback。

### Debug Triangle Fan

Composition Debug 继续读取原始 `cell_centers`、`cell_vertex_ids` 与 `vertex_positions`。对每个 Cell 逐边计算：

```text
center, vertex[i], vertex[(i + 1) % vertex_count]
```

三角形面积只用于判断是否提交显示 primitive，不会写回 SpatialGraph。直接使用 triangle primitive 后，实际启动 Debug Scene 的日志不再出现 `Invalid polygon data, triangulation failed`。
