# v2.3.5 — Mana Stability Decoupling

Version: v2.3.5  
Date: 2026-09-04  
Commit: uncommitted working tree based on `8e0666c` (`v2.3.4`)

## 目标

修正 Mana Stability 的推导，使其只表达长期 Persistent Disturbance 与 Background
Restoration Ability 的竞争关系。本阶段不是新增 Arcane 系统，也不修改 Concentration、
Flowability、Source/Sink、Transport Physics、Sparse Operator 或 BiCGSTAB。

## 修改内容

- 删除旧 Stability stress：`excess + mana_flowability * anomaly_gradient`。
- Stability 不再直接读取 Public/Raw Concentration、`C-B`、overload、Flowability、
  Web influence 或 drift magnitude。Raw Concentration 仅用于按现有 physics 计算真实
  transport face flux。
- 新增 signed transport net amount 计算：先累加全部 internal/boundary signed Face flux，
  再对每个 Cell 的 net amount-rate 取绝对值并除以 Cell area。
- `forcing_disturbance = source_rate + sink_rate`；Source 和 Sink 都视为持续外部强迫，
  不使用随 Concentration 变化的净 forcing rate。
- `persistent_disturbance = forcing_disturbance + transport_imbalance`。
- Background restoration ability 直接复用 solver 已有的
  `lerp(0.03, 0.15, background_stability)`。
- Final Stability 改为
  `restoration_rate / (restoration_rate + persistent_disturbance)`。
- 删除 `stability_min_resistance` 与 `stability_stress_response`，没有增加任何替代调节参数。
- 新增 disturbance、restoration、Flowability×Stability 四象限、Pearson correlation 以及
  Forcing Site 中心 Cell 的诊断。
- Debug Stability 侧栏同步显示新因果输入、四象限及 Site 简洁诊断。

## 关键实现

### 原公式问题

v2.3.4 及更早版本以 Raw anomaly 的正 excess 和 anomaly gradient 作为 stress，并以
Flowability 放大 gradient stress。这在公式中直接规定了“高于 Background 的浓度更
不稳定”及“高 Flowability 更不稳定”，超出了已确认的世界概念。

Background Stability 的正式定义没有改变：它表示当地将受扰 Mana 状态恢复到
Background Mana 的能力。新公式直接使用已有 restoration rate，不再构造额外的
`0.15 + ...` resistance。

### Persistent Disturbance

Forcing disturbance 使用 `source_rate + sink_rate`，表达 forcing mechanism 本身的持续
强度。它不会因 Source/Sink 在当前 C 下的净变化率抵消，也不会重新绑定 Concentration。

Transport disturbance 严格复用 v2.3.4 Face 数据与 flux 语义：

- internal diffusion：`G * ((C_a-B_a) - (C_b-B_b))`；
- internal drift：signed velocity 对应的 upwind Raw C；
- boundary diffusion：`G * (C_i-B_i)`；
- boundary drift：outflow 使用 Raw C，inflow ghost 使用 Background Mana。

每条 Face 先以方向符号累加到相邻 Cell。只有全部 Face 汇总后才计算
`transport_imbalance = abs(transport_net_amount) / cell_area`。因此高 gross throughput
若 inflow/outflow 平衡，不会直接降低 Stability；Leyline 可以同时高流动且高稳定。
反之，远离 Web 的 Source/Sink 仍能以 forcing disturbance 形成低流动、低稳定区域。
