# v2.1.3 Arcane Web Density Adjustment

- Version: v2.1.3
- Date: 2026-09-02
- Baseline: 当前 v2.1 Arcane Web + Large Domain mixture
- Commit: 未提交

## 目标

只降低 Arcane Web 的整体密度，增大平均网孔尺度与 Junction 间距，减少满屏多边形/砖块堆砌感，同时保持既有自然泡沫网、闭环和直线拓扑语义。

## 修改内容

`ArcaneWebSettings.web_nucleus_min_separation` 默认值由：

```text
170.0
```

改为：

```text
210.0
```

同步更新正式测试中的默认值、Poisson separation 描述及 radius factor 检查基准。Radius factor 检查使用 settings 中的正式 separation，不复制另一个权重参数。

## 保持不变

- `web_generation_margin = 300.0`
- 当前 normal/Large Domain Power Weight mixture：
  - Large probability：0.15
  - normal radius factor：0.25–0.70
  - Large radius factor：0.90–1.20
- AWEB stable seed domain
- deterministic Bridson Poisson-disk sampling
- weighted Power Diagram 与世界裁切
- Ley Node / Edge topology
- Structural Importance
- Debug 结构与绘制
- Composition 与其他世界层
- 其他参数

没有增加曲线、spline、Noise displacement 或其他拓扑参数。

## 视觉验收

Seed 1 的 Arcane Web Debug 与现有 Domain overlay 已实际 OpenGL 渲染：

- 网孔尺度明显增大，整体比 separation 170 基线更稀疏。
- Junction 之间的视觉距离增加，单个闭环更容易辨认。
- 网孔仍以不规则三岔泡沫/细胞结构组织，没有退化为树或规则蜂窝。
- normal/Large mixture 仍提供中等网孔主体与少量更大网孔。
- 没有出现新的成片极薄 Domain、异常碎裂区域或明显过大的空洞。
- 当前正式世界内出现两个 Ley Graph connected components；两者均由正常裁切后的泡沫网段组成，Validator 通过。

没有继续自动调参。临时验收图仅写入 `/tmp`，没有新增 `docs/screenshots/` 产物。
