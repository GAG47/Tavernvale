# Tavernvale v1.3 — Preliminary Climate

- Version: v1.3
- Date: 2026-08-29
- Commit: 未提交（工作区实现）

## 目标

在 v1.2 正式 `terrain_height` 之上生成可复用的初步气候数据：长期平均温度 `temperature` 与非负相对降水 `precipitation`。Generator 只读取 `SpatialGraph`、`TerrainHeightLayer` 与气候设置，不读取 raw composition，也不修改地形。相同 Generator 后续可以对水文整形后的正式高度再次运行，无需建立另一套 Final Climate 算法。

## 修改内容

- 新增 `WorldClimateSettings`，提供纬度窗口、Azgaar 默认赤道/极地温度、降水修正、六个风带角度与高度指数。
- 新增 `WorldClimateLayer`，以两个 `PackedFloat32Array` 保存 `temperature` 和 `precipitation`。
- 新增 `WorldClimateGenerator`，移植并适配 Azgaar 当前 Temperature 与 Precipitation Generator。
- 扩展现有 Composition Debug View，增加 Temperature 和 Precipitation 模式、相应统计、颜色与 Cell Inspect 字段。
- 新增一个快速 Climate 测试脚本；完整世界流程只使用 Seed 24680 的 400 Cell 世界。
- 未修改 Spatial Graph、Composition Generator、TerrainHeightProjector、Composition Templates 或 RNG 既有实现。

## 关键实现

### Azgaar Source

实现前核对了 Azgaar/Fantasy-Map-Generator 官方仓库当前 `master` 提交 `4eb71cfb89bebf987174623f9ccc0485bf328819`：

- [`temperature-generator.ts`](https://github.com/Azgaar/Fantasy-Map-Generator/blob/4eb71cfb89bebf987174623f9ccc0485bf328819/src/generators/temperature-generator.ts)
- [`precipitation-generator.ts`](https://github.com/Azgaar/Fantasy-Map-Generator/blob/4eb71cfb89bebf987174623f9ccc0485bf328819/src/generators/precipitation-generator.ts)
- [`public/main.js`](https://github.com/Azgaar/Fantasy-Map-Generator/blob/4eb71cfb89bebf987174623f9ccc0485bf328819/public/main.js) 的默认 climate options

### Latitude 与 Settings

`WorldClimateSettings` 默认值：

- `latitude_north = 70.0`
- `latitude_south = -20.0`
- `equator_temperature = 27.0`
- `north_pole_temperature = -30.0`
- `south_pole_temperature = -15.0`
- `precipitation_modifier = 1.0`
- `wind_bands = [225, 45, 225, 315, 135, 315]`
- `height_exponent = 2.0`

每个 Cell 的纬度按其实际 `cell_centers[cell_id].y` 计算：

```text
normalized_y = clamp(y / world_height, 0, 1)
latitude = lerp(latitude_north, latitude_south, normalized_y)
```

纬度不保存为独立数组。Debug Cell Inspect 和测试通过同一个 `WorldClimateGenerator.latitude_at/latitude_at_y` 计算。

### Temperature

温度结构沿用 Azgaar 当前算法：

- 热带区间 `+16° ~ -20°` 使用每纬度 `0.15°C` 的梯度。
- 热带边界到南北极分别线性插值到配置的极地温度。
- 高度降温沿用当前默认高度指数 `2.0` 与 `6.5°C / virtual km` 结构。
- 只在 `terrain_height >= 0.0` 时计算地形降温；所有负高度海洋都使用海平面温度，因此深海不会额外降温。

Azgaar 的温度算法依赖其 0..100 height。适配时只从正式 `terrain_height` 转换出算法内部的等价工作高度：海洋段使用 `20 + terrain_height / 5`，陆地段使用 `20 + terrain_height / 1.25`。Generator 不读取或接收 `continental_value`。正式输出保留 Float32 摄氏温度，没有复制 Azgaar `Int8Array` 的整数截断。

### Prevailing Winds 与 Precipitation

降水沿用 Azgaar 当前的逐行/逐列风传递结构：

- Stable Cell ID 原本就是 `row * columns + column`，因此沿用 `columns/rows` 做西风、东风、北风与南风扫描。
- 六个 30° 风带由可配置 `wind_bands` 角度决定水汽进入方向。
- 沿用 18 个绝对纬度 5° band 的降水修正数组。
- 水面逐格补充 humidity；海洋到陆地的边界得到 coastal precipitation。
- 陆地正常损失 humidity；下一格升高时按高度差及高度平方因子增加 orographic precipitation。
- 下一格超过 Azgaar 工作高度 85 时阻断剩余水汽，从而形成背风雨影。
- `temperature < -5°C` 的 Cell 不产生 flux，与 Azgaar 当前实现一致。
- 沿用 Azgaar 海岸降水的 `rand(10, 20)` 除数，但使用以 `SpatialGraph.config.seed` 派生的隔离 Climate RNG，避免读取 Godot 全局 RNG。

正式 `precipitation` 是非负相对量的 Float32 数据，不声明为 mm/year，也不叠加额外噪声。Float32 适配不会复制 Azgaar `Uint8Array` 的量化或溢出行为。

### Debug

继续使用原有 `world_composition_debug_view.tscn`、Triangle Fan Renderer、模板切换和 Cell 选择：

- `V`：Raw Composition
- `H`：Terrain Height
- `L`：Land / Water
- `C`：Temperature
- `P`：Precipitation
- `T`：切换 Composition Template
- `R`：Seed +1

Temperature 使用蓝 → 青 → 绿 → 黄 → 红色带；Precipitation 根据当前世界相对最大值使用黄褐 → 绿 → 青 → 蓝 → 深蓝色带。两者都不是灰度图。模式统计分别显示温度或降水的 Min / Max / Mean。Cell Inspect 显示 Cell ID、Terrain Height、Latitude、Temperature、Precipitation 与 Land / Water。

- Temperature：min `-21.58°C`，max `27.00°C`，mean `11.62°C`。北部明显冷于南部，高地形成同纬度冷斑，海洋温度只随纬度变化。
- Precipitation：min `0.00`，max `61.45`，mean `10.46`。主要海岸出现湿带，迎风坡增湿，山后与大陆内部可见更干区域。

最终 Climate、Terrain、Composition、Spatial 与 Debug 日志均无 `ERROR`、`SCRIPT ERROR` 或 `FAIL`。

## 已知问题

- v1.3 输出按定义是基于当前未经过水文整形高度的 Preliminary Climate；这不是 Final Climate。
- 降水继承 Azgaar 的规则行列风传递模型，不是动态大气环流或季节天气模拟。

## 设计偏差

无规格偏差。必要的数据结构适配是：从正式 `terrain_height` 推导算法内部工作高度；按 Cell 实际 Y 计算纬度；Float32 正式输出不使用 Azgaar 的 Int8/Uint8 量化；海岸随机项改用隔离的确定性 Climate RNG。未增加规格外气候、天气、水文、生态或资源算法。
