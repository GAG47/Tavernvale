# v2.3.0 — Arcane Transport Equilibrium

## 阶段职责与正式语义

本阶段在 v2.2.1 完成状态上新增 `ArcaneEnvironmentLayer`，没有恢复已放弃的旧 v2.3 加权合成，也没有反向修改 v1、v2.0、v2.1 或 v2.2。

- `Background Mana` 是当地自然平衡浓度 `B`，不是当前实际浓度。
- `Background Stability` 是环境抵抗扰动并把状态恢复到 `B` 的能力，不是当前最终稳定度。
- `Arcane Web` 是稳定、高 Flowability 的空间结构；它不是 Source、Sink 或 reservoir。
- `Arcane Circulation` 是与当前 concentration gradient 无关的长期定向 Arcane Drift；它只提供无量纲 drive，实际被搬运的量仍由当前位置的实际 Mana 决定。

正式输出严格只有三个与 SpatialGraph Cell ID 对齐的 `[0,1]` 数组：

- `mana_concentration`
- `mana_flowability`
- `mana_stability`

`web_influence`、`mana_disequilibrium`、Drift vector、restoration rate、Arcane Stress、gradient stress、resistance 和 iteration delta 都只存在于生成过程或 Debug diagnostics，不写入正式 Layer。

## Flowability 与 Drift 投影

对每个 Cell center 到每条 Leyline segment 计算 world-space 最短距离 `d`。半径 `R=55` 内：

```text
u = clamp(1 - d/R, 0, 1)
edge_influence = u²(3 - 2u)
web_influence = max(all edge_influence)
F = clamp(ambient + (1 - ambient) web_influence, 0, 1)
```

使用 `max` 而非求和，避免 Junction 因边数叠加而虚增 Flowability。`ambient_flowability=0.15`，所有 Leyline 使用同一种传导性质，`edge_flow` 不参与 Flowability。

一条 Web Edge 的 canonical 方向为 `node_a -> node_b`：

```text
q_e = clamp(edge_flow[e] / 2, -1, 1)
dir_e = normalize(node_b.position - node_a.position)
raw_drift_i = Σ edge_influence_e(i) q_e dir_e
V_i = arcane_drift_speed raw_drift_i
```

没有 per-world normalize，也没有从 Debug 图生成额外方向。

## Background equilibrium 与恢复

Solver 从 `C(0)=B` 开始。定义 Mana disequilibrium：

```text
mu_i = C_i - B_i
```

普通扩散使用 `mu_i-mu_j`，绝不使用 raw `C_i-C_j`。因此，即使 Background Mana 本身有明显空间梯度，只要 `C=B`，所有 `mu` 都为零，背景自然平衡不会被扩散抹掉。

Background Stability 通过恢复动力学参与：

```text
k_restore_i = lerp(0.03, 0.15, background_stability_i)
dC_restore/dt = k_restore_i (B_i - C_i) = -k_restore_i mu_i
delta_mass_restore_i = A_i k_restore_i (B_i - C_i) dt
```

即使 Background Stability 为零，仍有 `0.03` 的基础恢复率。

## Conservative finite-volume transport

每个内部 SpatialGraph shared face 只处理一次。对于 Cell `i,j`，共享面长度 `L_ij`、中心距离 `d_ij`、面积 `A_i,A_j`：

```text
F_ij = 0.5 (F_i + F_j)
Phi_diff(i->j) = diffusion_rate F_ij (mu_i - mu_j) L_ij / d_ij
```

面法向和 Drift flux 为：

```text
n_ij = normalize(center_j - center_i)
v_n = 0.5 (V_i + V_j) dot n_ij
C_upwind = C_i if v_n >= 0 else C_j
Phi_drift(i->j) = v_n C_upwind L_ij
Phi_total = Phi_diff + Phi_drift
```

更新的是 Mana amount：

```text
delta_mass_i -= Phi_total dt
delta_mass_j += Phi_total dt
C_new_i = C_i + delta_mass_i / A_i
```

所以关闭 restoration、boundary exchange 后，内部 diffusion 与 Drift 都成对守恒 `Σ C_i A_i`。Drift 使用 actual `C`，而不是 `mu`；它搬运实际存在的 Mana，且方向不依赖浓度梯度。

## Open world boundary

单 Cell boundary face 使用现有 Voronoi face 的真实 midpoint、length，以及从 Cell center 指向 midpoint 的 outward normal。Ghost state 为：

```text
C_out = B_i
mu_out = 0
```

Boundary diffusion 由 `mu_i-0` 驱动，距离使用 Cell center 到 face midpoint 的 world-space 距离。Boundary Drift 中，`V_i dot n_out > 0` 时以 `C_i` 流出，`<0` 时以 `B_i` 从外部背景环境流入。Boundary Exit 本身没有 Source/Sink 语义。

## Explicit Solver、timestep 与数值范围

实现为显式、守恒、迭代 Solver，没有 PCG、Jacobi、矩阵求逆或路径搜索。静态 transport coefficients 生成后，为每个 Cell 累加：

- restoration rate；
- finite-volume diffusion removal coefficient；
- positive outward advection coefficient。

然后：

```text
dt = min(solver_max_dt, solver_cfl_safety / max_rate)
```

每轮以 `max(abs(C_new-C))` 检查收敛。生成器显式报告 `dt`、iterations、final max delta、是否命中 iteration cap、finite 与 raw range；未收敛、非 finite 或明显越出 `[-1e-4, 1.0001]` 会使正式生成失败，不通过逐轮 clipping 掩盖问题。只在 Solver 成功后对可接受的浮点 epsilon 做最终 `[0,1]` clamp。

## Final Mana Stability

Stability 使用 anomaly `a=C-B`，而不是 raw concentration gradient：

```text
excess_i = max(a_i, 0)
local_gradient = Σ[L_ij abs(a_i-a_j)/d_ij] / ΣL_ij
gradient_stress_i = clamp(sqrt(A_i) local_gradient, 0, 1)
transport_gradient_stress_i = F_i gradient_stress_i
raw_arcane_stress_i = excess_i + transport_gradient_stress_i
arcane_stress_i = 2 raw_arcane_stress_i
resistance_i = 0.15 + 0.85 background_stability_i
mana_stability_i = resistance_i / (resistance_i + arcane_stress_i)
```

因此 `Background Stability != Final Mana Stability`。低 Background Stability 表示扰动发生时恢复/抵抗较弱；如果 `C=B` 且 anomaly gradient 为零，Arcane Stress 就是零，Final Mana Stability 仍严格为 1。Mana depletion 本阶段不作为爆发压力。

没有加入 Flow Conflict、Junction/degree penalty、Structural Importance 或 Betweenness。
