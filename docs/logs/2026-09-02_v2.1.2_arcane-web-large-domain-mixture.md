## 目标

保持普通 Arcane Nucleus 的既有 Power Weight 分布，以固定 15% deterministic 分支增加少量 Large Domain 倾向。目标是让中等网孔继续占主体，同时出现少量明显的大网孔，避免通过扩大所有 Nucleus 的连续随机范围制造大量极薄、小碎片 Domain。

## 修改内容

每个按 x/y 稳定排序后的 Nucleus 从当前 AWEB RNG stream 固定读取两个 deterministic uniform 值：第一个判断是否为 Large，第二个在对应分支内生成 radius factor。

```text
if deterministic_uniform_01 < 0.15:
    radius_factor = lerp(0.90, 1.20, deterministic_uniform_01)
else:
    radius_factor = lerp(0.25, 0.70, deterministic_uniform_01)

radius = web_nucleus_min_separation * radius_factor
power_weight = radius * radius
```

固定常量：

- `large_domain_probability = 0.15`
- normal radius factor：`0.25–0.70`
- Large radius factor：`0.90–1.20`

`sample_weighted_nuclei` 的内部结果附带 `is_large` 标记，用于正式测试和 Seed 1 统计；ArcaneWebLayer 的正式 Domain/Node/Edge 输出结构没有改变。

## 保持不变

- `web_nucleus_min_separation = 170.0`
- `web_generation_margin = 300.0`
- AWEB stable seed salt
- Bridson Poisson-disk sampling
- Power Diagram、裁切、Ley Node 与 Ley Edge 构造
- Structural Importance
- Composition
- Debug 结构
- 其他正式参数

没有加入 target Large count、按世界强制补 Large Domain、按面积调整、自动重抽或 relaxation。

## 视觉验收

Seed 1 的 Arcane Web Debug 与现有 Domain overlay 均已实际 OpenGL 渲染：

- 中等网孔仍然占绝大多数，没有变成整体放大的连续分布。
- 出现少量清晰的大网孔，主要分布在中央、上中与右侧局部，面积观感约为普通网孔的数倍。
- 没有出现上一种宽连续范围产生的成片极薄、小碎片 Domain。
- 局部仍自然存在少数较小网孔和短 Edge，但没有形成新的薄片群或碎裂区域。
- 网络保持单一 Connected Component，并保留 31 的 Cycle Rank。
