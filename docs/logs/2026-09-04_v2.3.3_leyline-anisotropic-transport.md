# v2.3.3 — Leyline Anisotropic Transport

Date: 2026-09-04

## Why transport changed

v2.3.2 made Natural Arcane Forcing properly local: every Source/Sink has a 30-unit
core and fixed integrated power rather than defining the final anomaly radius. That
exposed the remaining transport problem. The legacy scalar Flowability enhancement
raised diffusion in every direction near a Leyline, while its fixed drift scale was
too small in world units. Localized anomalies therefore stayed close to their cores
instead of using the Arcane Web as narrow, longitudinally conductive paths.

v2.3.3 keeps `mu = C - B`, Background Restoration, open boundaries, localized
Source/Sink forcing, upwind drift of actual `C`, and the Stability/Stress formulas.
Only the way transport consumes the existing Web and Circulation changes.

## Ambient and anisotropic diffusion

Ambient space now has an isotropic physical diffusivity of 56 world-units squared
per solver time. For each Cell, one merged Cell-by-Edge projection accumulates the
maximum smoothstep Web influence, a symmetric transport tensor, and a signed drift
vector. With edge tangent `t` and influence `w`:

```text
T_i += w outer(t, t)
V_i += w edge_flow_e 90 t
```

The tensor is represented internally by `(T_xx, T_xy, T_yy)`. Its maximum
eigenvalue is computed analytically:

```text
lambda_max = 0.5 * (a + c + sqrt(max(0, (a-c)^2 + 4b^2)))
```

When `lambda_max > 1`, the entire tensor is divided by it. Junctions can retain
several conductive directions, but no direction receives more than one unit of
Leyline enhancement and node degree never grants a bonus.

For a Cell connection direction `n`, the internal face tensor and alignment are:

```text
T_face = 0.5 * (T_i + T_j)
alignment = clamp(n^T T_face n, 0, 1)
D_face = 56 * (1 + (9 - 1) * alignment)
```

Thus a connection along a Leyline reaches 504, while a connection crossing it stays
at the ambient value 56. Formal scalar `mana_flowability` remains the unchanged
proximity query `0.15 + 0.85 * max(edge_influence)` and is not multiplied into
physical diffusion. Boundary diffusion applies the same alignment using the Cell
tensor and outward direction.

The passive internal face flux remains pairwise conservative:

```text
G_face = D_face L_ij / d_ij
Phi_diff(i -> j) = G_face (mu_i - mu_j)
```

The length estimates behind the defaults are `sqrt(56 / 0.09) ~= 25` units for
ambient space and `sqrt(504 / 0.09) ~= 75` units along a passive Leyline.

## World-space Arcane Drift

The new drift coefficient means world units per solver time per unit `edge_flow`.
No per-world normalization, magnitude clamp, or Junction normalization is applied.
The sign of the unchanged v2.2 flow chooses the direction. Internal faces cache:

```text
v_n = 0.5 * (V_i + V_j) dot n
A_face = v_n L_ij
Phi_drift = A_face * C_i, A_face >= 0
Phi_drift = A_face * C_j, A_face < 0
```

Open boundary outflow continues to use `C_i`; inflow uses `B_i`. At typical
`abs(edge_flow) ~= 0.25`, velocity is about 22.5 units per solver time and the
advection/restoration scale `v/k` is about 250 units.

## Projection, caches, CFL, and convergence

The former duplicated Web and Drift projections are merged into one Leyline
Transport Projection. Geometry, tangent, distance, tensor eigenvalue, face alignment,
diffusion conductance, and drift coefficient are all computed before iteration.
Each iteration only evaluates anomalies, cached face fluxes, restoration, forcing,
and concentration updates.

The global explicit timestep includes restoration, outgoing directional diffusion,
positive outgoing drift, and `P+K`:

```text
dt = min(1.0, 0.40 / max_local_removal_rate)
```

The iteration limit is 1200 and epsilon remains `1e-5`. Seed 1's irregular Voronoi
mesh contains small Cells under high parallel conductivity, so the strict CFL gives
`dt = 0.004581018`. After 1200 iterations the result is finite but has not converged:
final delta is `0.000120893`, raw range is `[0.109179332, 1.493594762]`, and 50 of
20,000 raw Cells exceed one. No Solver replacement or epsilon relaxation was made.
The formal layer retains its pre-existing `[0,1]` output contract, while diagnostics
explicitly retain `converged=false`, `hit_iteration_cap=true`, raw range, and range
status rather than claiming convergence.

## Settings and zero regression

diffusivity 56, parallel multiplier 9, drift-per-flow 90, restoration 0.03/0.15,
CFL safety 0.40, max dt 1, max iterations 1200, epsilon `1e-5`, Stability resistance
0.15, and Stress response 2.0. The two superseded coefficient names were removed
without aliases, including executable tests and repository log references.

All 19 repository `*_test.gd` scripts pass. This includes the new 10-group
anisotropic transport/calibration suite, 13 Arcane Environment groups, 18 localized
forcing groups, 12 Final Pipeline groups, and every v1 Natural Geography, v2.0
