# v1.7.1 Province Type Suitability Selection

- Version: v1.7.1
- Date: 2026-08-29
- Commit: 未提交

## 目标

将 Geologic Province seed 的固定类型轮换改为由基础先验和当前陆块 terrain suitability 共同决定的 deterministic 加权选择，允许不适合的 Province 在具体世界中完全不出现；保留 v1.7 的 seed placement、graph expansion、Material、Physical Properties 及后续 Pipeline 行为。

## 修改内容

- 删除按 `seed_index % 20` 强制分配 Province 类型的固定序列。
- 将 v1.7 的近似类型比例保存为 `PROVINCE_BASE_PRIOR`，只作为出现倾向，不再作为配额。
- 对每个陆地连通块复用现有 Cell-level suitability，计算各大陆 Province 的 top candidate mean。
- 每个 Province seed 使用 `base_prior × landmass_suitability` 权重和 salted deterministic 值选择类型。
- 类型选定后继续调用原有 `_choose_region_seed()`；Province graph expansion 没有修改。
- 增加平坦、山地、长海岸和零 suitability 的小型人工测试，没有增加批量 Seed 测试。

## 关键实现

### Base Prior

`GeologyGenerator.PROVINCE_BASE_PRIOR` 保存以下固定值：

| Province | Prior |
| --- | ---: |
| Craton | 0.30 |
| Orogenic Belt | 0.25 |
| Sedimentary Basin | 0.25 |
| Passive Margin | 0.15 |
| Volcanic Province | 0.05 |

Oceanic Crust 的 prior 为 0；Ocean Cell 仍由原有逻辑直接赋值，不进入大陆 Province 竞争。

### Landmass Suitability

每个陆地连通块分别处理。对每一种大陆 Province：

1. 读取该陆块所有 Cell 的现有 Province suitability。
2. 排序后取最高的一组候选值。
3. 代表样本数为陆块 Cell 数的 10%，下限 1、上限 64。
4. 使用这些 top candidates 的平均值作为 `landmass_suitability[type]`。

该聚合保留局部适宜区域的影响，避免用全陆块简单平均稀释只需要局部出现的 Province。由于同一轮 Province seed 创建期间陆块 terrain 和 Cell suitability 不变，该代表值只计算一次并供该陆块的所有 seed 复用。

### Deterministic 类型选择

每个新 seed 的类型权重为：

```text
type_weight = PROVINCE_BASE_PRIOR[type] × landmass_suitability[type]
```

以 World Seed、landmass component ID、seed index 和独立 salt 生成 `[0, 1)` deterministic 值，在累计权重上选择 Province。权重为 0 的具体类型不会被选择，也没有“至少一个 Orogenic / Volcanic”等补偿逻辑。类型选定后的 `_choose_region_seed()`、multi-source graph expansion、continuity 行为及小陆块的单-seed 数量处理均沿用原实现。

### 人工地形结果

| Case | Result |
| --- | ---: |
| Flat Landmass Orogenic Cell ratio | 9.475% |
| Flat Orogenic selection weight | 0.04875 |
| Mountainous Orogenic selection weight | 0.23875 |
| Inland Passive Margin selection weight | 0.06525 |
| Long-coast Passive Margin selection weight | 0.07685 |

另以 Orogenic 或 Volcanic suitability 精确为 0 的权重数组遍历 100 个 deterministic samples，零权重类型均未被选择。

## 测试

Geology 测试新增并验证：

1. 相同 Terrain + Seed 的 Province 和 Material 结果完全一致。
2. 平坦低 relief 大陆不再承受原固定 25% Orogenic 类型配额。
3. 山地高 relief 地形的 Orogenic 选择权重明显高于平坦地形。
4. 长而低缓的海岸提高 Passive Margin 选择权重。
5. suitability 为 0 的 Province 不会被固定序列强制选择。
