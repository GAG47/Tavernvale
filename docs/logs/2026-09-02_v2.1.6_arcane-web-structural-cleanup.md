# v2.1.6 Arcane Web Structural Cleanup

- Version: v2.1.6
- Date: 2026-09-02
- Baseline: `504a2c7`（v2.1.4）
- Commit: 未提交

## 目标

移除 v2.1 Arcane Web 中没有世界观依据的 Structural Importance。v2.1 的正式职责收束为生成稳定、有环、不规则的 world-space Arcane Web 几何骨架；不在本阶段决定 Leyline 强弱、主魔脉、Nexus 强度、Mana Flow 或 Arcane Circulation。

## 修改内容

### 正式数据

`ArcaneWebNode` 删除：

- `structural_importance`

最终正式字段为：

- `id`
- `world_position`
- `kind`

`ArcaneWebEdge` 删除：

- `structural_importance`

最终正式字段为：

- `id`
- `node_a_id`
- `node_b_id`
- `length`

没有增加任何替代强度、等级或图论指标字段。

### Centrality 与 Generator

完整删除 `ArcaneWebCentrality` 及对应 Godot UID，其中包括 weighted Dijkstra、Brandes dependency accumulation、node betweenness 与 edge betweenness normalization。

`ArcaneWebGenerator` 删除拓扑生成完成后的 centrality calculation；`ArcaneWebLayer` 同时删除 `importance_time_ms`。Incidence index、Validator 和总生成 timing 保留。

### ArcaneWebDomain 语义

`ArcaneWebDomain` 保留 `id`、`nucleus_position`、`power_weight` 与 `polygon`，用于 weighted Power Diagram 几何生成、Debug 与后续 world-space query。

它是 Arcane Web 的几何生成/查询辅助结构，不表示具有不同魔法性质的正式世界板块。

### Validator、Statistics 与 Tests

删除：

- Node/Edge `structural_importance` range validation
- Edge/Node Importance statistics
- Importance timing statistics
- 人工 Brandes centrality correctness test
- Determinism signature 中的 importance 数据

保留 Determinism、Different Seed、Resolution Independence、Poisson Separation、Power Diagram Correctness、Weight Effect、Boundary Cropping、Topology、Junction/Boundary Exit、Cycle Rank 与 incidence query。

Arcane Web tests 由 9 个 test groups 收束为 8 个几何 test groups。

### Debug

Arcane Web View 删除 Structural Importance 到线宽、亮度、alpha 和 Node size 的全部映射：

- 所有 Leyline：统一 `1.5 px`、统一青蓝色与 alpha
- 普通 Junction：统一 `3.5 px` 半径、统一浅青色
- Boundary Exit：保留独立橙色标记，统一 `3.0 px` 半径

删除 Debug Statistics 中的 Edge/Node Importance 与 Importance timing。Domain toggle 完全保留。

没有加入随机粗细、Noise 粗细、Edge Length 粗细、Degree 粗细、Spline、Curve 或 displacement。
