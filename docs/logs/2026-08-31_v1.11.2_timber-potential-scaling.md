# v1.11.2 Timber Potential Scaling

- Version: v1.11.2
- Date: 2026-08-31
- Commit: 未提交

## Scope

本版本只调整 Timber Potential 对现有 `vegetation_potential` 的尺度解释。Woody Biome Factor Table、Soil Support、Ecology、Biome、Soil 与其余七类 Resource Potential 均保持不变；没有增加 threshold、Settings、normalization、forest coverage 或 secondary biome。

## Formula

旧公式：

```text
timber = vegetation_potential × woody_biome_factor × soil_support
```

新公式：

```text
timber_vegetation_support = sqrt(clamp(vegetation_potential, 0, 1))
timber = timber_vegetation_support × woody_biome_factor × soil_support
soil_support = 0.70 + 0.15 × soil_depth + 0.15 × soil_fertility
```

Biome 继续表示主导生态环境而非 100% 地表覆盖。平方根映射只缓和 vegetation 与 woody biome factor 的双重线性压制，没有改变正式 Ecology 输入。

## Debug

Timber Cell Inspector 显示：

- Vegetation Potential
- Timber Vegetation Support
- Woody Biome Factor
- Soil Support

现有 `B` Hold Biome Reference 保持不变，可在不改变 Resources / Timber Panel 与 Inspector 的情况下临时对照 Biome 地图。

## Regression

- Agriculture
- Forage
- Construction Stone
- Base Metal
- Precious Mineral
- Freshwater Aquatic
- Coastal Aquatic

因此其余七类 Resource Potential 为零回归。
