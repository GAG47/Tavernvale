# Tavernvale v1.1.2 — Spatial Shared Voronoi Topology Rework

- Version: v1.1.2
- Date: 2026-08-27
- Commit: working tree based on `0595de1`

## 目标

用一次 Delaunay 的共享拓扑取代逐 Cell Voronoi clipping 与坐标 epsilon 合并，使 Triangle、Voronoi Vertex、Dual Edge、Cell Neighbor 和 Border 身份全部来自离散拓扑；同时把 Standard World 改为 2000×1000 / 20000 个真实 Cell，并通过 Seed 1～100 的完整验收。

## 原问题与修复原则

旧 Spatial 为每个 Cell 独立执行 half-plane clipping，再按坐标距离合并理论共享的 Vertex。Vertex identity 因此依赖 `vertex_merge_epsilon`，Seed 改变后可能发生未合并、错误合并、内部单 Cell Edge 或 canonical merge 后的零长 Edge，最终使 Generator 返回 `null` 并连带阻断 Composition。

本次不再通过调大 epsilon 修补。真实 Seed 与外围 Boundary Seed 一次参加 Delaunay；Delaunay Triangle ID 是唯一 Voronoi Vertex ID，normalized primal edge 的两个 adjacent Triangle ID 是 dual edge 两端。坐标只负责外心位置，不决定任何拓扑身份。

## 修改内容

- Standard World 默认值改为 `world_width=2000`、`world_height=1000`、`target_cell_count=20000`，保持 2:1 与参数化配置。
- 保留原 jittered near-regular grid 真实 Seed 生成；默认自然得到 200 columns × 100 rows，即精确 20000 个 Real Cell。
- 按 Azgaar `getBoundaryPoints` 规则生成完整外圈：spacing 为 `round(sqrt(area/target), 2)`，offset 约 `-spacing`，Boundary 间隔约 `spacing*2`。默认得到 300 个 Boundary Seed。
- Stable Point ID 保持 Real `0..19999`，Boundary 从 `20000` 追加；Delaunay 返回 ID 在引擎适配后映射回这一编号。
- 保留完整 Triangle、point→incident triangles、normalized primal edge→adjacent triangle IDs。
- 每个 Triangle 只计算一次标准外心；Triangle ID 直接索引 `vertex_positions`、float64 原始外心分量与 `vertex_cells`。
- 真实 Cell 的 incident Triangle 通过共享 primal edge adjacency 环绕遍历成完整 cycle，不再依靠坐标接近关系建立顺序。
- real-real primal edge 产生两 Cell dual edge与双向 Neighbor；real-boundary 产生单 Cell 外围 dual edge并标记 Border；boundary-boundary 不进入最终 edge data。
- Border 新定义为“真实 Seed 至少有一个 Boundary Seed Delaunay 邻居”。Polygon 和 Vertex 可超出逻辑矩形。
- 删除硬矩形面积覆盖、硬边坐标、Vertex 必须在 Rect 内等旧约束。
- Spatial Debug 增加 Real Seed、Boundary Seed、Delaunay、Voronoi Vertex、Real Polygon、Border 的独立观察入口；Composition Debug 对超出部分进行遮罩，只显示逻辑 2000×1000。
- Composition primitives、六模板脚本及参数未修改；默认回归自动使用现有 20k `blobPower=0.99` / `linePower=0.82`。

## 删除的旧架构

- 删除 `voronoi_builder.gd` 及 UID。
- 删除 per-cell half-plane clipping 与 Candidate Neighbor clipping 路径。
- 删除 `vertex_merge_epsilon_for_size`、polygon coordinate canonicalization、连续近似点清理与 vertex bucket merge。
- 删除按世界矩形边线判断 Border Edge 的工具与 Validator 逻辑。
- 未保留 legacy fallback、compatibility switch 或第二套 Voronoi Generator。

## 关键实现

### Boundary 与 Stable ID

`SpatialGraph.cell_count()` 仍只等于 `cell_centers.size()`。Boundary 位置单独存放在 `boundary_seed_positions`，只通过 `all_seed_count()` / `seed_position()` 供底层 Delaunay 和 Debug 使用，永远不进入真实 Cell、Neighbor 或 Composition 数组。

### Triangle 即 Voronoi Vertex

`delaunay_triangles[T*3..T*3+2]` 定义 Triangle `T`。标准 circumcenter 的原始 double 分量保存在 `vertex_position_x64/y64[T]`，Godot 可渲染投影保存在 `vertex_positions[T]`；`cell_vertex_ids` 直接引用 `T`，不存在坐标 hash、bucket lookup 或 merge。

退化三角形会报告 Triangle ID、三个 Point ID、三个坐标和 denominator，然后 Generator 失败；没有随机抖动、三角形中心替代、跳过或 Triangle 合并。

### Edge、Neighbor 与 Border

每个 Triangle 的 AB、BC、CA 写入 canonical primal edge registry。具有两个 adjacent Triangle 的 real-related primal edge，其 adjacent Triangle ID 直接成为 canonical Voronoi edge vertex IDs。`edge_seed_ids` 保留对应 primal edge，Validator 因而能双向重建并核对 dual topology。

Neighbor 当且仅当存在 real-real primal edge，distance 是两个真实 Seed 的欧氏距离。Border 当且仅当存在 real-boundary primal edge，不再检查 Polygon 是否触碰 `x=0/2000` 或 `y=0/1000`。

### Godot 数值与插入顺序适配

当前 Godot 4.7.1 的 `Geometry2D.triangulate_delaunay` 对“大点集 + 共线外圈”的插入顺序敏感；原始 real-first 输入在 Seed 85 返回重叠 Triangle，使一个 edge 有 4 个 adjacent triangles。引擎调用层因此临时以 Boundary-first 顺序提交同一完整点集，并在返回后立即映射回 Real-first / Boundary-appended stable IDs。没有过滤、补造或合并 Triangle，且仍只有一次 Delaunay 调用。

GDScript `float` 保留的两个不同 float64 外心，在当前单精度 `Vector2` 中可能投影为同一点（Seed 3 的原始差约 `3.27e-5`）。实现保留原始 float64 外心；若拓扑已知的 dual edge 仅在 Vector2 投影后不可区分，则沿原始差值主轴做确定性的最小可表示分离。此处理不改变 Triangle/Vertex ID、Edge ownership 或 Neighbor identity。

## Validator

新 Validator 从 `delaunay_triangles` 反向重建 point incident triangles 与 primal edge registry，并严格检查：

- 每个真实 Seed 恰有一个 Cell，Boundary ID 不出现在真实 Cell / Neighbor 数组。
- Triangle 数与 Voronoi Vertex 数一一对应，Triangle seed ID、Vertex ID、float64/Vector2 坐标均合法且有限。
- 每个 Cell 至少 3 个不重复 Vertex，Vertex 集合恰等于该 Seed 的 incident Triangle 集合，ordered cycle 的每条边都存在于 dual registry，Polygon 包含 Seed 且面积为正。
- `vertex_cells` 与 Triangle 中过滤后的 Real Seed 精确一致并双向引用。
- real-related primal edge 恰有两个 adjacent triangles；dual edge 的 Vertex ID 恰为这两个 Triangle ID，长度大于 geometry edge epsilon。
- real-real edge 恰属于两个真实 Cell；real-boundary edge 恰属于一个真实 Cell；boundary-boundary edge 不进入最终 registry。
- Neighbor 合法、无自身、无重复、双向，distance 正确，并与 real-real edge 当且仅当一致。
- Border flag 与 real-boundary adjacency 当且仅当一致；真实 Cell Graph 整体连通。
- `validate_determinism` 会生成两次并比较完整 Spatial 数据。

已删除 Cell Area Sum 等于世界面积、单 Cell Edge 位于硬矩形、Polygon Vertex 位于矩形内等旧检查。

交叉核对当前 Azgaar：

- [`src/utils/graphUtils.ts`](https://github.com/Azgaar/Fantasy-Map-Generator/blob/master/src/utils/graphUtils.ts)：spacing、约 `-spacing` offset、`spacing*2` Boundary 间隔、real + boundary 同次 Delaunay、真实点数量与辅助点分离。
- [`src/generators/voronoi.ts`](https://github.com/Azgaar/Fantasy-Map-Generator/blob/master/src/generators/voronoi.ts)：Triangle circumcenter 作为 Voronoi Vertex、halfedge/triangle adjacency、around-point Cell Vertex、辅助 Cell 过滤与 near-border 判定思想。

Tavernvale 保留任务指定的 Stable Real Cell ID、SpatialGraph 接口、2000×1000 / 20000 默认值和 Composition 隔离。除下述 Godot 适配外，没有发现提示词与当前 Azgaar 核心行为冲突。

## 已知问题

- 完全规则、`jitter=0` 的共圆格点会产生数学上重合的相邻 Triangle 外心；按任务要求不合并 Triangle、不随机补救，因此这种非 Standard 配置会由零长 Edge 校验明确失败。正式 Standard World 使用当前默认 `jitter=0.9`，Seed 1～100 全部通过。
- `vertex_positions` 是当前 Godot 构建的单精度 `Vector2` 渲染投影；原始标准外心另存为 float64 分量。极少量仅由投影造成的重合使用上述最小确定性分离。

## 设计偏差

1. Azgaar/Delaunator 直接接收 real-first + boundary-appended 数组；Godot 4.7.1 在 Seed 85 对该插入顺序返回非流形重叠 Triangle。Tavernvale 在单次 Geometry2D 调用前做 Boundary-first 临时排列，调用后映射回任务要求的 Stable ID。原因、复现现象与影响如上，未引入第三方 Delaunay、未过滤或补造 Triangle。
2. 理论上 `vertex_positions[T]` 应直接是标准外心；受当前 Godot `Vector2` 单精度限制，distinct float64 外心可能投影为同一点。实现保留未经修改的 float64 外心，并只对拓扑已确定且投影退化的 dual edge调整渲染坐标。该偏差只影响亚像素几何位置，不影响任何拓扑身份。
