## 目标

只增强 Arcane Web Debug 的视觉层级，使连续的 `structural_importance` 能清楚表现为主魔脉、普通魔脉和较弱支脉。正式网络数据、算法、参数和拓扑全部保持不变。

## 修改内容

仅修改统一 World Composition Debug View 中 `_draw_arcane_web()` 的绘制映射。

### Edge 映射

对正式 `edge.structural_importance` 先 clamp 到 `[0,1]`，再使用绝对参考值 0.20 的平滑映射：

```text
importance = clamp(edge.structural_importance, 0, 1)
emphasis = smoothstep(0.0, 0.20, importance)
brightness = emphasis ^ 0.85

line_width = 0.75 + 7.25 * emphasis ^ 1.35
line_color = lerp(
    rgba(0.07, 0.20, 0.36, 0.42),
    rgba(0.76, 0.98, 1.00, 1.00),
    brightness
)
```

因此 Debug line width 连续映射范围为 0.75–8.0 px。低 importance Edge 保持可见但暗且细；中 importance Edge 具有正常可读宽度；高 importance Edge 接近亮青白并显著加粗。

### Node 映射

对正式 `node.structural_importance` 使用绝对参考值 0.22 的平滑映射：

```text
importance = clamp(node.structural_importance, 0, 1)
emphasis = smoothstep(0.0, 0.22, importance)
node_radius = 2.0 + 10.5 * emphasis ^ 1.35
```

Debug node radius 连续映射范围为 2.0–12.5 px。Node 颜色也以 `emphasis ^ 0.70` 平滑趋近高亮青白；Boundary Exit 仍保留橙色基色，普通 Junction 使用青色基色。

所有映射均连续，没有建立一级、二级或三级魔脉分类，也没有按当前世界重新 normalize importance。
