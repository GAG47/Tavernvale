# v1.7.2 Local Province Seed Suitability

- Version: v1.7.2
- Date: 2026-08-29
- Commit: 未提交

## 目标

将 Geologic Province seed 的类型选择从整块 landmass 共用一套主要权重，调整为先确定 seed 的空间位置，再使用该位置周边的 projected terrain 特征进行 deterministic weighted selection；保留 v1.7.1 Base Prior 和弱 landmass context，不修改 Province expansion、Material、Physical Properties 或后续 Pipeline。

## 修改内容

- Province seed 流程调整为：先按原有分离度与 deterministic variation 选择 Cell，再计算该 Cell 的 local suitability，最后选择 Province 类型。
- 新增有限 Graph neighborhood 的 projected terrain 特征聚合。
- 为五类大陆 Province 增加独立的 local suitability 权重公式，仍使用连续权重而非硬分类。
- v1.7.1 landmass suitability 保留，但只映射为 `0.90–1.10` 的弱 modifier。
- 增加同一陆块中的 Mountain、Lowland、Coastal、Interior 和不同局部权重人工测试。
- 未增加批量 Seed 测试。

## 关键实现

### Seed 生成顺序

每个陆地连通块的 seed count、上限和处理范围不变。每个 seed 依次执行：

1. `_choose_region_seed()` 使用原有 seed 间空间分离度系数 `0.65` 和 salted deterministic variation `0.08` 选择尚未使用的 Cell。
2. 从该 Cell 的 v1.2 projected `terrain_height` 计算 local terrain features。
3. 计算五类大陆 Province 的 local suitability。
4. 计算 `base_prior × local_suitability × weak_landmass_modifier`。
5. 使用 World Seed、landmass component ID、seed index 和独立 salt 进行 deterministic weighted selection。
6. 类型确定后进入未修改的 Province multi-source graph expansion。

原流程中“先选择类型，再按该类型 suitability 选择 seed Cell”的顺序已移除。Seed count、spacing 的距离计算、Province expansion cost、continuity 行为和 Material Patch generation 均未修改。

### Local Neighborhood

局部分析只沿当前 landmass 的 Land Cell 遍历，不跨 Ocean：

- 2 graph rings：计算 `local_mean_height`、局部最低/最高高度及 `local_relief`。
- 4 graph rings：计算较大邻域平均高度；与 2-ring mean 比较得到 `relative_lowland`。
- 现有 coast-distance BFS：把 seed 的 coast steps 映射为 `coast_proximity` / `interior`。

输入是传给 `GeologyGenerator.generate()` 的 projected `TerrainHeightLayer`。Ocean Cell 仍在 seed 处理之前直接赋值 Oceanic Crust，不参与陆地类型选择。

### Local Suitability

所有特征和 suitability 都连续归一化到 `[0, 1]`，没有 `if relief > threshold` 等硬分类：

- Craton：主要偏好 interior、低 relief 和中低 local mean height，不要求 relative lowland。
- Orogenic Belt：local mean height 与 local relief 为主要正向因素，其中 relief 权重为 `0.50`。
- Sedimentary Basin：偏好 relative lowland、低 relief、interior 和较低 local mean height；未读取任何 Hydrology closed basin 数据。
- Passive Margin：主要偏好 coast proximity，并偏好低 relief 和中低 local mean height。
- Volcanic Province：延续低 Base Prior，local suitability 弱结合 Orogenic-like terrain、coast、height 和 relief，不强制出现。

Base Prior 保持 v1.7.1 的 `0.30 / 0.25 / 0.25 / 0.15 / 0.05` 不变。

### Weak Landmass Context

v1.7.1 的 top candidate landmass suitability 仍被计算，但不再直接作为主要 selection suitability。每种 Province 的 landmass 值只映射为：

```text
landmass_modifier = lerp(0.90, 1.10, landmass_suitability)
weight = base_prior × local_suitability × landmass_modifier
```

因此 landmass context 最多只造成约 ±10% 修正，不能覆盖 local suitability 的主要差异。零 local suitability 乘弱修正后仍然为零；没有 mandatory quota 或类型补偿。

### 人工测试结果

| Comparison | Preferred weight | Reference weight |
| --- | ---: | ---: |
| Mountain / Flat Orogenic | 0.20361 | 0.03515 |
| Lowland / Level Sedimentary | 0.26005 | 0.21033 |
| Coastal / Interior Passive | 0.15714 | 0.06922 |
| Interior / Coastal Craton | 0.32252 | 0.20733 |

Mountain 与 Flat 候选位于同一人工 landmass，最终完整 weight arrays 不相同。相同 Seed + Terrain 的 Province、Material 及 Physical Properties 结果仍完全一致。
