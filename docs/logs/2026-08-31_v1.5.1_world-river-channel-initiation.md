# v1.5.1 River Channel & Network Filtering

- Version: v1.5.1
- Date: 2026-08-31
- Commit: 未提交

## 目标

将 World River 的职责拆开：`river_runoff_threshold = 5000.0` 作为候选河道与 Ecology / Soil 水文影响的参考尺度；`formal_river_min_cells = 3` 和 `formal_river_min_discharge = 20000.0` 决定候选水系是否成为正式 World River；Natural Main-Upstream Headwater Tracing 只负责把已经确认的重要河网沿真实 `flow_to` 主上游路径延伸到自然源头。

## 正式生成顺序

1. 正常计算 `local_runoff`、`flow_to`、`flow_accumulation`。
2. 以 `flow_accumulation >= 5000.0` 的陆地 Cell 构建候选 River Network。
3. 仅保留 Cell Count 至少为 3 且 mouth discharge 至少为 20000 的候选 Network。
4. 找出每个保留 Network 的全部正式 Source；每个 Source 独立选择最大 `flow_accumulation` 的陆地 upstream predecessor，相同 accumulation 时选择较小 Cell ID，并沿该唯一主链追踪到不存在 upstream land predecessor。
5. 新增 Cell 加入其最终流入的原 Network；生成器断言 tracing 前后 Network Count 相同。
6. 基于最终正式 mask 重新计算 Strahler Order、连续 `river_network_id` 与 `HydrologyRiverNetwork` metadata。

Tracing 不使用额外 headwater threshold，也不修改 `flow_to`、`flow_accumulation`、Watershed、runoff 或 terrain。Hydrology Conditioning 的独立 `breach_min_inflow = 5000.0` 保持原样，未与 River threshold 合并。

Ecology 与 Soil 继续仅使用真实 `flow_accumulation` 和 Hydrology settings 中的 5000 threshold；Natural tracing 新增的 World River 身份不会产生额外生态或土壤 bonus。

## Validator 与测试

Validator 额外确认：

- 最终 `river_order` 与最终正式 mask 的 Strahler 结果一致。
- 每个 Network 满足 3 Cell 与 20000 mouth discharge 下限，source / mouth metadata 合法。
- River Cell 沿 `flow_to` 连续，正式河网不会结束在普通 Land Cell。
- threshold 以下的 traced Cell 留在同一 Watershed、沿最大 accumulation predecessor 主链，并最终进入原候选河道。
- 每个正式 Source 已到 Natural Headwater，tracing 不产生新侧枝。

Formal Hydrology deterministic tests 增加到 8 组，覆盖最大 accumulation predecessor、稳定 Cell ID tie-break、Natural 停止、多正式 Source 独立延伸、无新 branch、Network identity、原始水文数组不变，以及低于 20000 discharge 的候选水系不会因 tracing 复活。
