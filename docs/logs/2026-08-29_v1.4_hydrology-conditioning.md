# Hydrology Conditioning

- Version: v1.4
- Date: 2026-08-29
- Commit: 未提交

## 目标

在不改变陆海拓扑、不使用降水、也不提前生成河流或湖泊的前提下，对 v1.3 正式 `terrain_height` 做最小排水调节。输出调节后的正式高度与 `closed_basin_id`，使每个非封闭盆地陆地 Cell 都能沿严格下降路径到达 Water、世界边界或已编号封闭盆地。

## 修改内容

- 新增独立 `HydrologyConditioner`、设置、结果与 Validator。
- 在当前 Voronoi `SpatialGraph.cell_neighbors` 上实现图版 Priority-Flood，不假设四邻域、八邻域或规则网格。
- 以 Water Cell 与 `cell_is_border` Cell 为 Priority-Flood 出口，计算每个 Cell 的最低可达洪泛高度和出口父节点。
- 将洪泛高度高于原高度的相邻陆地 Cell 聚合为 Depression，记录范围、最低点、spill height 与最大填深。
- 小且浅的 Depression 使用有限 Fill；其他 Depression 优先使用受距离与成本限制的 Least-Cost Breach；失败后仅允许有限回退 Fill，否则编号为 Closed Basin。
- Breach 搜索状态包含 Cell、路径长度、累计削低量和当前通道高度。每一步把通道限制为比前一 Cell 至少低 `flow_epsilon`，Cost 为路径上实际削低量之和。
- 最后对非终点 Flat 施加仅用于建立严格流向的微小高度梯度，再由 Validator 反向验证所有陆地均可到达有效终点。
- Debug 流水线现在将 Projector 输出交给 Conditioner，并把结果的 `terrain_height` 作为 Climate 的输入；没有修改 TerrainHeightProjector 或 Climate Generator。
- 现有 World Debug View 增加 `D` 模式，显示 Fill、Carve、Closed Basin 和调节统计/Cell 明细。

## 关键实现

### 正式结果

`HydrologyConditioningResult` 的正式输出为：

- `terrain_height: PackedFloat32Array`
- `closed_basin_id: PackedInt32Array`，`-1` 表示非封闭盆地，`0+` 表示封闭盆地编号

同一结果对象还携带 `original_height`、`height_delta`、`conditioning_action` 与统计，供当前 Debug 和 Validator 使用；World pipeline 只需继续持有新的正式 `terrain_height` 和 `closed_basin_id`。

### Settings 默认值

- `flow_epsilon = 0.001`：在 `[-100, 100]` Float32 范围内可稳定表达的严格坡降。
- `small_fill_max_cells = 4`：初始小坑 Fill 的最大范围。
- `small_fill_max_depth = 1.0`：初始小坑 Fill 的最大填深。
- `max_breach_distance = 12`：Breach 的最大图邻接步数。
- `max_breach_cost = 12.0`：Breach 路径允许的最大累计削低量。
- `fallback_fill_max_cells = 16`：Breach 失败后有限 Fill 的最大范围，防止浅但巨大的区域被整体抬升。
- `fallback_fill_max_depth = 2.0`：Breach 失败后有限 Fill 的最大填深。

这些是保守初始值，没有做 Seed 批量调参。

### Fill 与 Breach

Fill 沿 Priority-Flood 父节点从出口向坑内处理，仅把 Cell 抬到 `parent_height + flow_epsilon`，并拒绝超过高度上限的方案。

Breach 使用优先队列搜索相邻 Cell。状态 Cost 是为保持连续下降通道而产生的实际 `terrain_height` 削低量之和，不使用单纯几何距离；可接入 Water、世界边界，或已有严格下降路径且高度足够低的外部 Cell。搜索和最终应用都不把原 Land Cell 降到 `0` 以下。

### Closed Basin 与最终验证

超过 Fill 阈值、且在 Breach 距离/成本限制内找不到合理出口的 Depression 会按连通范围获得 Closed Basin ID。调节后 Validator 检查：

- 高度有限且位于 `[-100, 100]`；
- 每个 Cell 的 Land / Water 分类与输入完全一致；
- 从 Water、世界边界与 Closed Basin 反向沿严格升高邻接传播后，不存在未覆盖陆地 Cell。

严格下降关系本身不能形成环；未覆盖 Cell 会作为 Validator 错误，不会被静默接受。

执行：

```text
godot --headless --path . --script tests/worldgen/hydrology/hydrology_conditioner_test.gd
godot --headless --path . --script tests/worldgen/climate/world_climate_generator_test.gd
godot --headless --path . --script tests/worldgen/terrain/terrain_height_projector_test.gd
godot --headless --path . --script tests/worldgen/composition/world_composition_generator_test.gd

godot --headless --path . --quit-after 8 tests/worldgen/composition/world_composition_debug_view.tscn
```

结果：

- Hydrology Conditioning：6/6 组通过，包括正常坡地不变、单 Cell Fill、受阻谷地 Breach、深盆 Closed Basin、Flat 严格坡降、拓扑/范围/最终排水。
- Preliminary Climate：3/3 组通过。
- Terrain Height Foundation：3/3 组通过。
- World Composition：15/15 组通过。
- Spatial Skeleton：10/10 组通过。
- Debug 场景成功启动并完成 20,000 Cell 生成，无脚本错误。

额外对默认 Seed 1、20,000 Cell 世界执行一次 v1.4 结果检查：Conditioning 约 1167 ms；初始 Sink 742，Fill 28，Breach 194，Closed Basin 63，修改 Cell 3.595%，最大抬升约 1.254，最大削低约 8.751，Validator 无错误。该检查只运行一个固定世界，没有增加 Seed Sweep。

## 已知问题

- 当前阈值是 v1.4 的保守初始值，尚未通过大批量 Seed 调参；这是任务要求下的刻意限制。
- `conditioning_action` 对 Flat 微调统一记为 `FILL`，但 `Filled Depression Count` 只统计实际 Depression 分类产生的 Fill，不把纯 Flat 微调计为 Depression。
- v1.4 只保证地形排水结构，不输出正式 Flow Direction、流量、河流、湖泊或 Watershed。

## 设计偏差

无。实现没有修改 Spatial Generator、Composition Generator、TerrainHeightProjector 或 Climate Generator，也没有使用 precipitation 或提前实现 v1.5 数据。
