# v1.6.1 Preliminary Flow Integration

- Version: v1.6.1
- Date: 2026-08-29
- Commit: 未提交

## 目标

在 Preliminary Climate 与 Hydrology Conditioning 之间加入只包含基础汇流数据的 Preliminary Flow，使非小型/浅层 Depression 只有在实际汇集水量达到门槛后才允许尝试现有 Least-Cost Breach，同时让 Preliminary Flow 与 Formal Hydrology 复用同一套 runoff、Flow Direction 和 Flow Accumulation 实现。

## 修改内容

- 从 `WorldHydrologyGenerator` 抽出 `HydrologyFlowCalculator`，集中计算 local runoff、最陡下降邻居和拓扑累计。
- 新增中间数据 `HydrologyFlowResult`，只保存 `local_runoff`、`flow_to`、`flow_accumulation`。
- 新增 `PreliminaryFlowGenerator`，使用 projected terrain、Preliminary precipitation 和现有 `WorldHydrologySettings.runoff_modifier`。
- Preliminary Flow 允许未 Conditioning 地形中的 Sink，以 `HydrologyFlowResult.FLOW_TO_SINK` 标记，累计水量在 Sink 停止。
- `HydrologyConditioner.condition` 新增 Preliminary Flow 输入。
- `HydrologyConditioningSettings` 新增独立参数 `breach_min_inflow = 5000.0`。
- 非 small/shallow Depression 的 inflow 由组件内部所有终止 Sink 的 Preliminary Flow accumulation 求和；达到门槛才调用原有 Least-Cost Breach。
- 低于门槛时跳过 Breach，继续执行原有 fallback limited Fill 或 Closed Basin。
- Debug pipeline 调整为 Projected Terrain → Preliminary Climate → Preliminary Flow → Conditioning → Final Climate → Formal Hydrology。
- Hydrology Conditioning Debug 增加 sufficient-inflow breach、low-inflow rejection 和门槛统计。

## 关键实现

`HydrologyFlowCalculator` 保留 v1.5 的原始公式与选择规则：

```text
local_runoff = precipitation × cell_area × runoff_modifier
slope = (height_current - height_neighbor) / neighbor_distance
```

Flow Direction 仍选择严格更低邻居中的最大下降坡度，坡度近似相同时仍按较小 Cell ID 决定。Flow Accumulation 仍使用 indegree/topological order，每个 Cell 的 local runoff 只累计一次。

Preliminary Flow 不运行 Fill、Breach、Watershed、River Network 或 Strahler Order。其 Sink 使用负终止标记，不人为制造下游。

Depression inflow 不做逐 Cell 全图回溯。Conditioner 已有 Priority-Flood Depression component，直接遍历组件 Cell，将其中 `flow_to == FLOW_TO_SINK` 的 `flow_accumulation` 相加。严格下降的 Flow DAG 保证不同终止 Sink 的上游集合互不重复。

Small/shallow Depression 的直接 Fill 判定保持在 inflow gate 之前。其他 Depression 的判定顺序变为：

```text
depression_inflow >= breach_min_inflow
→ 才运行原 Least-Cost Breach
→ 仍必须满足 max_breach_distance / max_breach_cost / 原安全限制

depression_inflow < breach_min_inflow
→ 跳过 Breach
→ 原 fallback limited Fill 或 Closed Basin
```

Flow 只决定是否允许尝试 Breach，没有参与 carve path、carve height 或 carve depth。
