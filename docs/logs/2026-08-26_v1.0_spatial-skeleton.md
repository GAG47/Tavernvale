# World Natural Generation v1.0 / Spatial Skeleton

- Version: World Natural Generation v1.0 / Spatial Skeleton
- Date: 2026-08-26
- Commit: `28f3bda`

## 目标

建立有限矩形世界的稳定 Cell Graph 空间骨架，使后续世界数据能够通过稳定 Cell ID 关联到统一的空间单位。

## 修改内容

- 建立独立的 Deterministic Spatial RNG 和可序列化 `SpatialConfig`。
- 生成 row-major 稳定 ID 的 Jittered Grid。
- 构建 Delaunay 邻接、矩形裁剪 Voronoi Polygon、Cell Area、Neighbor Distance、Border 标记和共享 Vertex 数据。
- 建立纯数据 `SpatialGraph`、Spatial Validator、headless 自动测试和交互式 Debug View。

## 修改文件

- 新增当时位于 `world/worldgen/random/` 和 `world/worldgen/spatial/` 的 Runtime 脚本。
- 新增 `tests/worldgen/spatial/` 下的测试脚本与 Debug Scene。
- 修改 `project.godot`，将 Spatial Debug View 设置为主场景。

## 关键实现

- World Seed 经固定 Spatial Salt 派生独立 RNG 状态。
- Cell Seed 采用轻微扰动的规则点阵，ID 按 row-major 保持稳定。
- 使用 `Geometry2D.triangulate_delaunay()` 建立三角形及邻接关系。
- 使用 Delaunay 邻接对应的垂直平分线，对世界矩形执行 Half-Plane Polygon Clipping。
- 使用 Shoelace Formula 计算 Cell Area，并保存 Neighbor Distance、Vertex Position、Cell Vertex ID 和 Vertex Cells。
- Validator 检查 Polygon、邻接、连通性、边界和总面积覆盖。
- Debug View 支持 Voronoi、Delaunay、Seed、Cell ID、Border 和选中 Cell/Neighbor 显示。

## 测试

- 提交中包含 8 个实际测试函数，覆盖确定性、不同 Seed、无 Jitter、默认 Jitter、邻接对称与连通、面积与 Polygon、配置序列化再生成、默认 10k 与 Validator。
- 当时测试成功文案将组数硬编码为 9，与实际函数数不一致；具体历史耗时没有保存在仓库中，因此不补写性能数字。
- 该版本已完成项目验收，但后来发现下述拓扑问题。

## 已知问题

1. Delaunay Neighbor 被直接作为最终 Neighbor，边界情况下可能与最终 Voronoi Shared Edge 不一致。
2. Vertex 去重仅依赖单一量化 Key，可能把理论上相同的浮点 Vertex 分成不同 Vertex ID。

这两个问题后来在 v1.0.1 / `47ec1ca` 中修复。
