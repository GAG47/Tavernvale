# v2.1.1 Arcane Web Weight Range Adjustment

- Version: v2.1.1
- Date: 2026-09-02
- Baseline: 当前未提交的 v2.1 Arcane Web
- Commit: 未提交

## 目标

只扩大 Arcane Nucleus Power Weight radius 的固定分布范围，让 Seed 1 的 Arcane Domain 与网孔呈现更明显的大、中、小差异，减少原本偏平均的细胞网观感。

## 修改内容

Power Weight 计算由：

```text
radius = separation × lerp(0.25, 0.70, deterministic_uniform_01)
weight = radius²
```

调整为：

```text
radius = separation × lerp(0.15, 1.00, deterministic_uniform_01)
weight = radius²
```

在正式 separation 170.0 下，radius 规则范围由 42.5–119.0 world units 改为 25.5–170.0 world units。

同步修改正式测试对固定 factor 与生成 radius 范围的断言。

## 保持不变

- `web_nucleus_min_separation = 170.0`
- `web_generation_margin = 300.0`
- AWEB stable seed salt 与 deterministic RNG stream
- Bridson Poisson-disk sampling 与 nucleus positions/order
- weighted Power Diagram、world cropping 与 Node/Edge topology 构造方式
- Structural Importance
- Debug 绘制与交互
- Composition、Arcane Field 与所有自然地理 Layer
- 其他参数

由于 Poisson sampling 在 weight 抽取前完成且 RNG 调用顺序未改变，Seed 1 的 nucleus count 与 nucleus positions 保持不变；仅 Power Weight 以及由此产生的 Power Diagram geometry 改变。

## 视觉验收

Seed 1 Debug 已实际运行并渲染。与原 0.25–0.70 结果相比，大面积、普通面积与较小面积 Domain 的层级差异更清楚；中心偏左及上部出现更宽、更拉长的大网孔，同时小网孔与短边仍然存在。整体细胞尺寸不再像原范围那样平均，目标中的大/中/小网孔差异明显增强。
