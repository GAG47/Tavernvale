## 目标

在 v2.0 Arcane Field 之后增加独立的世界级 Arcane Web。正式几何只由 World Seed 与 World Extent 决定，不读取 SpatialGraph 的 Cell Count、Cell ID 或空间分辨率，也不读取任何 v1 自然地理 Layer 或 v2.0 Arcane Field 值。

本阶段正式输出仅包含 Arcane Domain、Ley Node、Ley Edge 与 Node/Edge Structural Importance；没有实现 Coupling、Source/Sink、Mana Flow、Concentration、Phenomena、Resource 或文明系统，也没有曲线与噪声位移后处理。

## 修改内容

- 新增 `ArcaneWebSettings`，只暴露 generation margin 与 nucleus minimum separation。
- 新增 `ArcaneWebDomain`、`ArcaneWebNode`、`ArcaneWebEdge` 与 `ArcaneWebLayer` 正式数据模型。
- 新增 deterministic Bridson Poisson-disk Sampling、weighted Power Diagram、真实共享边界提取、世界裁切、稳定 Node/Edge ID 与 weighted Brandes centrality。
- 新增 `ArcaneWebValidator` 与完整 Web 统计。
- 在统一 Debug 的 Arcane Page 增加第 3 个 View `Arcane Web`，并增加可切换 Domain overlay。
- 在固定完整 pipeline test 中把 Arcane Web 接在 Arcane Field 后，验证 v2.0 与全部 v1 Layer 不变。
- 新增正式 v2.1 generator tests。

## 正式输入与输出

`ArcaneWebGenerator.generate(world_seed, world_width, world_height, settings)` 的正式输入为：

- World Seed
- World Width
- World Height
- `ArcaneWebSettings`

输出 `ArcaneWebLayer`，正式集合为：

- `domains: Array[ArcaneWebDomain]`
- `nodes: Array[ArcaneWebNode]`
- `edges: Array[ArcaneWebEdge]`

Layer 另保存输入、settings 副本、generated nucleus count 与阶段 timing，供验证和 Debug 统计使用。`incident_edge_ids(node_id)` 通过生成完成后建立的轻量 incidence index 查询；没有为 SpatialGraph Cells 预存 Web 数据。

### ArcaneWebDomain

- `id`
- `nucleus_position`
- `power_weight`
- `polygon`

只保存与正式 World Extent 有非空交集的 Domain。ID 按 nucleus position 的 x/y 顺序在可见 Domain 中连续分配。

### ArcaneWebNode

- `id`
- `world_position`
- `kind`：`JUNCTION` 或 `BOUNDARY_EXIT`
- `structural_importance`

Node endpoint 以 world-size epsilon 合并，然后按 world position 的 x/y 顺序连续分配 ID。正式世界边界上的裁断点为 Boundary Exit，其余真实 Power Diagram vertex 为 Junction。

### ArcaneWebEdge

- `id`
- `node_a_id`
- `node_b_id`
- `length`
- `structural_importance`

始终满足 `node_a_id < node_b_id`，并按 `(node_a_id, node_b_id)` 连续分配 ID。几何是两个 Node 之间的 world-space 直线段，没有 spline、Bezier、随机弯曲或 noise displacement。

## Seed 与固定参数

Arcane Web 使用现有 `DeterministicRng.stable_mix`：

```text
ARCANE_WEB_SEED_SALT = 0x41574542  # AWEB
```

固定设置与算法常量：

| 项目 | 值 |
|---|---:|
| Web Generation Margin | 300.0 world units |
| Nucleus Minimum Separation | 170.0 world units |
| Bridson k | 30 |
| Weight Radius Range | separation × 0.25 .. separation × 0.70 |
| Seed 1 实际 radius 范围规则 | 42.5 .. 119.0 world units |

Weight radius 在稳定 x/y nucleus ordering 后从同一 AWEB deterministic RNG stream 取得 uniform `[0,1)`，正式 weight 为 `radius²`。没有 per-world min/max normalization。

## Poisson-disk Sampling

生成矩形为：

```text
[-300, world_width + 300] × [-300, world_height + 300]
```

Bridson active list、背景 grid、candidate angle/radius 与 active index 均由隔离的 AWEB RNG 决定。Nucleus 位置从始至终是未吸附的 `Vector2` world-space coordinate。完成后按 x ascending、y ascending 排序。

相同 World Seed、World Width 与 World Height 在不同 SpatialGraph target cell count/resolution 下生成逐值相同的 Domain、Node、Edge 与 Importance。Arcane Web 不依赖 SpatialGraph resolution。

## Weighted Power Diagram

正式 power distance 为：

```text
power_i(x) = |x - position_i|² - weight_i
```

每个 Power Cell 从扩展生成矩形开始，对所有其他 nucleus 应用 `power_i <= power_j` 的线性 half-plane clipping，之后再裁切到正式 World Extent。

Ley Edge 不从最终 Domain polygon 的矩形边取边。实现逐一检查每个 nucleus pair：

1. 构造 `power_i == power_j` 的线性 bisector。
2. 将直线先限制到扩展生成矩形。
3. 对所有其他 nucleus 的 `power_i <= power_k` 约束收缩有效参数区间。
4. 最后把真实共享线段裁切到正式 World Extent。
5. 仅保留长度大于 geometry epsilon 的线段。

因此 World Rectangle clipping edge 不会被当成 Leyline；真实 Leyline 可在世界边界形成 Boundary Exit 后离开模拟范围，但不会沿矩形边框行走。

## Structural Importance

使用标准 weighted Brandes algorithm：

- shortest-path edge weight：`ArcaneWebEdge.length`
- graph semantics：undirected
- Node normalization：`1 / ((V - 1)(V - 2))` 乘 undirected Brandes raw score
- Edge normalization：`1 / (V(V - 1))` 乘 undirected Brandes raw score

这是标准全图 normalized betweenness，结果 clamp 到 `[0,1]` 只用于浮点安全；没有按当前世界 min/max 再归一化。它只表示拓扑结构重要性，不表示 Mana、Flux、Coupling 或 Strength。

## Validator

Validator 检查：

- extent、Domain nucleus/weight/polygon、Node position、Edge length 与 Importance finite；
- Domain polygon 至少三个点、面积大于 epsilon、完全位于正式 World Extent；
- Domain/Node/Edge ID 连续且排序稳定；
- Edge endpoint 合法、不同且满足 `node_a_id < node_b_id`；
- Edge 不重复、长度与直线 endpoint 距离一致；
- 所有 Edge 位于世界范围内；
- Boundary Exit 必须位于世界边界；
- degree 1 只能是合法 Boundary Exit；
-内部 Junction degree 至少为 3；
- 不允许沿任一正式 World Rectangle 边形成 Ley Edge。

- 整体明显呈不规则泡沫/细胞网，并有 28 个自然 cycle rank，不是树状人工支线。

- 87 个内部 Junction 全部 degree 3；没有 degree 2 或 degree 4+ 内部节点。
