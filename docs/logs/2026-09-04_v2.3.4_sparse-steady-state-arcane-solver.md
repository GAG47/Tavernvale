# v2.3.4 — Sparse Steady-State Arcane Solver

Version: v2.3.4  
Date: 2026-09-04  
Commit: uncommitted working tree based on `34650e9` (`v2.3.3`)

## 目标

在不修改 v2.3.3 transport、Source/Sink、Stability 公式和参数的前提下，将
`ArcaneEnvironmentGenerator.generate()` 从显式时间推进正式切换到 matrix-free
steady-state `A*C=b` 与 Jacobi-preconditioned BiCGSTAB；同时落实 Internal Raw
Concentration、Public Mana Concentration 和 Long-term Mana Stability 的最终语义。

## 修改内容

- 正式生产路径依次执行 Leyline transport projection、Face precompute、linear
  operator build、BiCGSTAB solve、Public Concentration 映射和 Long-term Stability。
- 删除生产代码中的 CFL、dt、显式 concentration integration loop、1200 次 runtime
  iterations、runtime convergence epsilon 和对应 diagnostics。
- 从 `ArcaneEnvironmentSettings` 删除 `solver_cfl_safety`、`solver_max_dt`、
  `solver_max_iterations`、`solver_convergence_epsilon`，没有保留 alias 或 solver mode。
- BiCGSTAB 的 relative/absolute tolerance、iteration cap、breakdown tolerance 只作为
  solver 内部实现常量；生产失败时不 fallback 到 explicit solver。
- Public `mana_concentration=clamp(raw_concentration, 0, 1)`。这是把内部物理状态映射到
  正式标准量表的语义转换，不是隐藏数值错误。Raw `C>1` 表示长期 Mana overload。
- Stability 的 anomaly、excess 和 gradient 全部使用 clamp 前的 Raw Concentration。
  Stability 明确定义为长期区域环境属性，而非瞬时爆发事件。
- Raw Concentration 只在生成过程和 diagnostics 中存在，没有加入正式 Layer。
- Validator 继续严格验证三个正式数组的 size、finite 和 `[0,1]`；solver report 允许
  Raw `C>1`，但拒绝 breakdown、non-convergence、non-finite 和 Raw `C<-1e-6`。
- Debug Concentration 显示 Public/Raw statistics、三个 overload tier 和 maximum overload；
  Stability 页面更名为 Long-term Mana Stability，并注明计算源为 Raw Concentration。
- v2.3.3 explicit solver 只保留为 `tests/` 下的 equation/reference harness。

## 关键实现

### 方程与 Solver

v2.3.3 完整 amount-rate 经审计严格满足 `F(C)=b-A*C`。Restoration、internal/boundary
diffusion、fixed-sign upwind drift、Source `P*(1-C)` 与 Sink `-K*C` 均为 affine terms；
transport tensor、velocity、Face coefficient 和 forcing rate 均不依赖当前 `C`。
因此 steady state 严格为 `A*C=b`。

Operator 保存 diagonal/RHS 及内部 Face coupling，`apply_into()` matrix-free 地计算
`A*x`。Signed upwind drift 使矩阵非对称，因此使用 BiCGSTAB 而非 CG；Jacobi
preconditioner 为 `z_i=r_i/A_ii`。所有工作向量为预分配 `PackedFloat64Array`。

Feasibility 已确认：

- operator equivalence maximum error：`3.1e-13`；
- sparse steady state 对 high-accuracy explicit small reference：maximum MAE
  `1.911118e-8`，maximum error `3.958997e-8`；
- Seed 1：146 iterations，relative residual `8.262718e-8`，L-infinity residual
  `4.159708e-5`，converged，no breakdown；
- old/new anomaly Pearson `0.960416`，sign agreement `98.273%`；
- 原显式实现约 43.349 s，feasibility sparse 路径约 4.031 s。

先前 MODEL RANGE GATE 仅因 Raw `C>1` 阻止切换。后续正式设计决定明确 `[0,1]`
是 Public standardized scale，而不是 Internal Raw physical state 的绝对上限，因此该
Gate 的上界失败条件被解除。没有添加 capacity、nonlinear saturation、sigmoid/logit，
也没有修改 physics。Raw 明显负值仍是非法状态。

### 正式数据语义

`ArcaneEnvironmentLayer` 仍严格只有 `mana_concentration`、`mana_flowability`、
`mana_stability` 三个 Cell-aligned arrays。Raw solve result 先用于 Stability，再映射为
Public Concentration；不持久化 Raw array。

Long-term Mana Stability 表示 Background equilibrium/restoration、Natural Source/Sink、
Arcane Web transport 与 Circulation 共同作用后，区域长期维持 overload 或失稳环境的
倾向。公式保持 v2.3.3，仅将输入明确为 Raw anomaly。

Source/Sink 保持 v2.3.2 的位置、polarity、`core_radius=30` 与 `total_power=70`；所有
transport/Stability 参数保持 `radius=55`、ambient Flowability `0.15`、`D=56`、parallel
multiplier `9`、drift-per-flow `90`、restoration `0.03..0.15`、Stability
`0.15/2.0`。
