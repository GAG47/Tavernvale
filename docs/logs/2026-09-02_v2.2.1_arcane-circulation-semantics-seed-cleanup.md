## 目标

收紧 Arcane Circulation 的世界观语义与 World Seed 入口，并让 Debug 按理论 Flow 范围显示。本次不修改 circulation potential、Cell Cycle Superposition、Edge 左右 Domain 判定、signed flow 公式、Junction conservation 或任何 Arcane Web 几何。

## 正式语义

`circulation_potential` 表示 Arcane Medium / 魔力位面在大尺度上的长期 Arcane Circulation Potential。它是 Cell Cycle Superposition 的临时计算量，不是 Debug 随机值、为 Leyline 粗细生成的 Noise，也不是 `ArcaneWebDomain` 的魔法属性。

`ArcaneWebDomain` 仍然只是 Power Diagram 几何生成、world-space 查询和环流计算的辅助结构。

`edge_flow` 表示 Leyline 上长期平均的相对 Arcane Current / Mana Flow：

- `abs(edge_flow)`：相对长期流动强度
- `sign(edge_flow)`：相对 canonical `node_a_id -> node_b_id` 方向的流动方向

当前 Flow 没有绝对物理单位，不表示每秒 Mana 数量。`ArcaneCirculationLayer` 没有增加任何正式字段。

## World Seed 入口

Generator 正式入口由：

```gdscript
generate(arcane_web, world_seed)
```

收束为：

```gdscript
generate(arcane_web: ArcaneWebLayer) -> ArcaneCirculationLayer
```

Circulation seed 现在只能来自 `arcane_web.world_seed`，再通过既有 `DeterministicRng.stable_mix(world_seed, 0x43495243)` 派生 CIRC sub-seed。Generator、expected-flow helper 和 Validator 均不再接受独立 `world_seed`，因此不能构造 Seed 1 Web + Seed 2 Circulation。

Different Seed test 改为两条完整链路：

```text
World Seed 1 -> Arcane Web 1 -> Arcane Circulation 1
World Seed 2 -> Arcane Web 2 -> Arcane Circulation 2
```

测试验证相同 World Seed 完全 deterministic，不同 World Seed 至少部分 `edge_flow` 不同。

## Debug 映射

由于 potential 理论范围为 `[-1, 1]`，左右差值得到的 `edge_flow` 理论范围为 `[-2, 2]`。Debug 改为固定理论范围映射：

```text
display_strength = clamp(abs(edge_flow) / 2.0, 0.0, 1.0)
line_width = lerp(0.75, 6.0, display_strength)
```

亮度和 alpha 使用同一个 `display_strength` 连续插值。没有 per-world normalization，正式 Flow 数据与分布不受影响。
