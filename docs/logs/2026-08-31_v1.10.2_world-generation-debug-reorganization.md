## 目标

将统一 World Generation Debug 从持续累积的字母快捷键与阶段性控制台诊断，整理为稳定、可继续扩展的 `DebugPage + 页内 View` 工具。本版本不修改任何正式 WorldGen 数据、算法、参数或 Layer，也不进入 v1.11 Resource Potential。

## 控制方式

- `Tab`：下一 Page
- `Shift+Tab`：上一 Page
- `1~9`：选择当前 Page 中的 View；超出当前 Page 范围时安全忽略
- `T`：切换 Template
- `R`：Seed +1 并重新生成
- `Click`：Cell Inspector

旧的 V/H/L/C/P/D/F/N/W/G/M/B/S/U/K/E/O 及 Shift 组合不再选择 View。

右侧面板统一标题为 `Tavernvale World Generation Debug`，显示 Template、Seed、Cell Count、Current Page、Current View、当前 Page 的 View 列表与通用控制，不再展示所有历史快捷键或阶段版本标题。

## 历史诊断清理

从默认 regeneration 流程及 Debug 文件中删除了没有外部消费者的专用诊断与 helper：

- River Network 长度、出口、异常样本与短河专项统计
- mouth discharge threshold what-if
- pre/post `formal_river_min_cells` what-if
- main-upstream、natural headwater、headwater threshold tracing what-if
- River Bonus accumulation band / counterfactual moisture 统计
- v1.9.5 Water Balance precipitation percentile、Warm/Hot、Bottom 10% calibration 输出
- v1.9.6 Moisture Band calibration 输出
- Soil Material → Texture 临时统计
- Soil deposition depth / texture counterfactual 与 shift 统计
- Soil Depth 的 Formation / Erosion / Deposition calibration HUD；正式 Soil Depth 连续统计保留
- Ecological Moisture 的历史 `.50/.60/.70/.72` calibration threshold HUD；正式连续统计保留

正常启动与 regenerate 不再产生这些控制台表格。正式 View summary、Cell Inspector、世界生成、Validator 和独立 deterministic tests 保留。
