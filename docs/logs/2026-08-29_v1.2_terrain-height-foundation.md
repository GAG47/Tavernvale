# Tavernvale v1.2 — Terrain Height Foundation

- Version: v1.2
- Date: 2026-08-29
- Commit: 未提交（工作区实现）

## 目标

在现有 v1.1 Spatial Graph 与 Azgaar Composition 输出之后建立 Tavernvale 正式的标准化地表高度层。保留 Composition 的整数 `continental_value` 作为生成器内部值与 Debug 数据，通过独立投影器输出 `terrain_height ∈ [-100.0, 100.0]`，并保证新旧陆海分界完全一致。

## 修改内容

- 新增 `TerrainHeightProjector`，对 raw composition value 执行以 20 为海平面的分段线性映射与范围 clamp。
- 新增 `TerrainHeightLayer`，以 `PackedFloat32Array terrain_height` 保存每个 Stable Cell ID 对应的正式高度。
- `TerrainHeightLayer.is_land(cell_id)` 仅由 `terrain_height[cell_id] >= 0.0` 推导，不保存独立陆海数组或布尔字段。
- 扩展现有 Composition Debug View，可查看 Raw Composition、Terrain Height 与 Land / Water 三种模式。
- Terrain Height 模式使用八段地形色：深海深蓝、浅海浅蓝、低地绿色、中高地黄绿/黄褐/棕色、最高地形浅灰。
- Cell 点击信息增加 Raw Composition Value、Terrain Height 与 Land / Water。
- 新增快速 projector 测试；没有增加 Seed Sweep 或批量世界生成。

## 关键实现

`TerrainHeightProjector.project_value(raw)` 使用以下映射：

```text
raw < 20:  (raw - 20.0) * 5.0
raw >= 20: (raw - 20.0) * 1.25
result:     clampf(result, -100.0, 100.0)
```

`project(raw_composition)` 创建一个 `TerrainHeightLayer`，保持 Cell 数量及 Stable Cell ID 索引不变，并将每个整数 raw value 投影到 `PackedFloat32Array terrain_height`。正式 Terrain layer 不保存 raw composition，也不保存独立 `is_land` 真值。现有 `WorldCompositionGenerator`、`WorldCompositionLayer`、Composition Operations、Templates、Validator 与 RNG 源文件均未修改。

Debug 仍使用原有 Composition 场景、模板切换、Seed 切换、Cell 选择与 Triangle Fan Renderer：

- `V`：Raw Composition 灰度图。
- `H`：Terrain Height 八段地形色。
- `L`：由 `terrain_height >= 0.0` 得出的 Land / Water。
- `T`：切换 Composition Template。
- `R`：Seed 加一并重新生成。
