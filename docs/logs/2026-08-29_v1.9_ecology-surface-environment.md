## 目标

在 Final Terrain、Final Climate、Formal Hydrology、Geology 和 Surface Water 之后新增独立 Ecology 层，正式生成 Drainage、Ecological Moisture、Vegetation Potential 与 Biome。Ecology 只消费现有物理环境，不反向修改 Terrain、Climate、Hydrology、Geology 或 Lake。

- Final Pipeline 测试在 Surface Water 后接入 Ecology，并验证 Marine / Lake 优先级和 Validator。
- World Debug 在 Surface Water 后运行 Ecology，新增 Drainage、Ecological Moisture、Vegetation Potential 与 Biome 四个模式、对应统计和按模式裁剪的 Cell Inspect。
- 新增 13 组小型人工 Ecology 测试；未增加批量 Seed 测试。

## 关键实现

### 正式输出与 Pipeline

`EcologyLayer` 只保存四个 Cell Count 数组：

- `drainage_index: PackedFloat32Array`
- `ecological_moisture: PackedFloat32Array`
- `vegetation_potential: PackedFloat32Array`
- `biome_id: PackedInt32Array`

三个连续量均限制在 `[0, 1]`。没有新增 `is_forest`、`is_desert`、`is_wetland` 等重复字段，也没有保存 slope factor、river bonus 等中间值。

实际流程为：

```text
Projected Terrain
→ Geology
→ Preliminary Climate
→ Preliminary Flow
→ Hydrology Conditioning
→ Final Terrain
→ Final Climate
→ Formal Hydrology
→ Surface Water
→ Ecology
```

### Drainage

每个陆地非 Lake Cell 检查所有 Spatial neighbors，使用 Final Terrain 计算最大下降坡度：

```text
descending_slope = max(
    max(terrain_height[cell] - terrain_height[neighbor], 0)
    / cell_neighbor_distance
)

slope_factor = slope / (slope + slope_reference)
surface_escape = slope_factor
```

默认 `slope_reference = 0.05`。Closed Basin 的 `surface_escape` 乘 `0.35`，随后与 Geology permeability 作为两条独立排水路径合并：

```text
drainage_index = 1 - (1 - permeability) * (1 - surface_escape)
```

Ocean 和 Lake 的 Drainage 固定为 0，且在 Biome 分类时先于 Wetland 处理。

固定世界中 descending slope 的 Min / Max / Mean 为 `0.000000 / 23.919489 / 0.817954`，P25 / P50 / P75 为 `0.241968 / 0.495642 / 0.972501`。该尺度来自 normalized terrain-height units 除以 world-distance units；按任务固定的 `slope_reference = 0.05`，Drainage 分布明显偏高，因此未擅自重新调参。

### Ecological Moisture

Final precipitation 使用固定尺度映射：

```text
climate_supply = precipitation / (precipitation + 20.0)
```

`SurfaceWaterSettings.evaporation_factor()` 复用 v1.8 的 `-20°C ~ 35°C` 固定温度 anchors 和 smoothstep。Debug / Pipeline 将实际 v1.8 `SurfaceWaterSettings` 传给 Ecology，因此没有第二条温度蒸发曲线。

River Strength 直接读取 Final Hydrology 的 accumulation 和其 settings 中的现有 threshold：

```text
river_strength = clamp(
    log(1 + flow_accumulation / river_runoff_threshold) / log(21),
    0,
    1
)
river_bonus = river_strength * 0.20
```

Lake Shore 仅标记与 Lake Cell 直接相邻的一圈陆地 Cell，固定 bonus 为 `0.15`。

最终公式：

```text
base_retention = climate_supply
    * (1 - 0.30 * drainage_index)
    * (1 - 0.25 * evaporation_factor)

ecological_moisture = clamp(
    base_retention + river_bonus + lake_shore_bonus,
    0,
    1
)
```

未使用当前世界 min/max、percentile、rank、noise 或 Biome quota。

### Vegetation 与 Wetland

Temperature Suitability：

```text
cold_factor = smoothstep(-12, 8, temperature)
heat_factor = 1 - smoothstep(35, 48, temperature)
temperature_suitability = clamp(cold_factor * heat_factor, 0, 1)

vegetation_potential = clamp(
    pow(ecological_moisture, 0.8) * temperature_suitability,
    0,
    1
)
```

Ocean / Lake 的 Vegetation Potential 固定为 0。

Wetland 仅作为 Biome 分类内部条件：

```text
hydrology_support = max(river_strength, lake_shore ? 1 : 0)
closed basin: hydrology_support = max(hydrology_support, 0.5)

moisture >= 0.72
and drainage <= 0.30
and hydrology_support >= 0.35
```

没有新增正式 wetland score 或 boolean。

### Biome Matrix

`scripts/world/worldgen/ecology/ecology_catalog.gd` 独立保存 14 个 Biome enum、Temperature / Moisture bands 和固定二维矩阵。分类优先级为 Marine → Lake → Glacier（Land temperature `<= -10°C`）→ Wetland → Matrix。没有 Mountain Biome、动态阈值或比例配额。

### Debug

- `Shift+D`：Drainage，低值暗湿色、高值亮干色。
- `Shift+M`：Ecological Moisture，Brown / Yellow → Green / Blue。
- `Shift+V`：Vegetation Potential，裸地色 → 茂盛绿色，极冷区会因 Temperature Suitability 重新降低。
- `B`：Biome，每种 Biome 使用固定颜色。

三个连续场显示 terrestrial non-Lake Cells 的 Min / Max / Mean / P25 / P50 / P75。Biome 显示每种类型的总 Cell Count，以及其在 terrestrial non-Lake Cells 中的 Land %；Marine / Lake 的 Land % 为 0。另外单列 Wetland Cell Count。

Ecology 模式 Cell Inspect 固定显示 terrain height、Final temperature、Final precipitation、permeability、flow accumulation、lake ID，并按当前模式补充相关连续值与 Biome，避免无条件堆满全部中间量。信息行会按当前内容数量缩放行距与字体，保证 Biome 列表和 Inspect 能留在面板内。

## 测试

新增 13 组人工测试覆盖：

1. Permeability 增加不降低 Drainage。
2. 使用 neighbor distance 的坡度增加 Drainage。
3. Closed Basin 降低 surface escape，同时高 permeability Basin 仍可高 Drainage。
4. Precipitation 增加不降低 Moisture。
5. 高温蒸发不提高 Moisture，并验证共享 evaporation helper 保持 v1.8 endpoints。
6. Flow accumulation 增加 River Bonus，且 bonus 不超过 0.20。
7. 1-ring Lake Shore 增湿。
8. 温暖湿润区 Vegetation 高、极寒区明显降低。
9. Marine / Lake Vegetation 为 0。
10. Wetland 同时要求高 Moisture、低 Drainage 和 Hydrology Support。
11. 固定 Matrix 覆盖 Hot Desert、Grassland、Savanna、Taiga、Temperate Forest、Tropical Rainforest 和 Tundra。
12. 相同输入完全 deterministic。
13. 数组长度、连续值 finite/range、Validator 和全部上游输入不变。

## 已知问题

- 固定 Debug 世界的 Drainage 分布偏向高值（P50 `0.936054`）。这是当前 normalized terrain-height / world-distance slope 尺度与任务固定 `slope_reference = 0.05` 共同产生的直接结果；本版没有擅自调参或用 Biome quota 掩盖。
- 固定世界没有达到 Wetland、Temperate Rainforest 或 Tropical Rainforest 条件。这是连续场与固定 Matrix 的结果；人工测试确认这些分类路径可达。
- v1.9 按范围不处理 Soil、物种、succession、fire、seasons、agriculture、resources 或任何 Ecology feedback。
