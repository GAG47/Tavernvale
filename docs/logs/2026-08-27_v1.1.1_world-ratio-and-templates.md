# Tavernvale v1.1.1 World Ratio & Composition Templates

- Version: v1.1.1
- Date: 2026-08-27
- Commit: 0595de1

## 目标

将 Tavernvale 正式默认世界比例确定为 2:1，并在不调整 v1.1 大陆构图算法的前提下，把 World Composition 的正式模板从两个扩展为六个。本版本只增加 Add Primitive 和四个指定模板，不进入物理 Height、Sea Level 或其他 v1.2 内容。

- Debug View 的 `T` 键改为在六个模板之间循环，并明确显示模板名称、Seed、世界尺寸和 Cell 数量。
- Composition 测试扩展到六模板 determinism、默认 2:1 约 10k 生成、Add 行为及四个新模板的完整顺序。
- Spatial 测试增加默认尺寸、比例、target Cell Count 和稳定 grid dimensions 检查。
- v1.1 开发日志的 Commit 字段从基线 SHA 更新为实际完成 SHA `76959e1`，未修改其余历史内容。

## 默认世界比例

默认世界选择 1400×700，因此宽高比精确为 2:1。总面积为 980000，与此前 1000×1000 的 1000000 接近；在 `target_cell_count = 10000` 不变时，平均 Cell 面积和空间密度不会产生巨大变化。

target Cell Count 继续保持 10000，因为本任务改变的是世界形状，不是世界离散精度。现有 grid dimension 算法在 2:1 下自然得到 141 columns × 71 rows，即 10011 Cells，符合“约 10000”的目标。

Spatial 不需要算法修改。jittered grid、Delaunay、Voronoi、Candidate/Final Neighbor、vertex merge、edge registry、Stable Cell ID、topology 和 geometry epsilon 均未改动。

## Add Primitive

Add 是逐 Cell 的范围修改，不是传播算法：

- `Add value all`：处理全部值。
- `Add value land`：只处理 `continental_value >= 20`；负数增加不能把已选值降到 20 以下。
- `Add value min-max`：只处理旧值位于闭区间内的 Cell。
- 最终统一使用现有 clamp 0..100 后截断的 Uint8-style 写回。

测试覆盖 `Add 11 all`、正数上限、负数下限、land 参考值保护和普通数值范围选择。

## 六个正式 Template

1. Continents
2. Pangea
3. Archipelago
4. Mediterranean
5. Old World
6. Shattered

Continents 与 Pangea 的 Operation 数组保持 v1.1 原样。新增模板严格采用任务和 Azgaar 源码中的顺序：

- Archipelago：Add、Range、3 Hill、Smooth、Trough、vertical Strait、horizontal Strait。
- Mediterranean：2 Range、2 Hill、Multiply、negative Mask、Smooth、2 Hill、2 Trough。
- Old World：Range、3 Hill、Multiply、Smooth、2 Range、Strait、Trough、Pit。
- Shattered：Hill、Trough、Range、Pit。

除这六个模板外，没有加入其他 Azgaar 模板。

## Azgaar Source Fidelity Check

2026-08-27 交叉核对了 Azgaar/Fantasy-Map-Generator 当前 `master`：

- `src/generators/heightmap-generator.ts`
- `src/data/heightmap-templates.ts`

Archipelago、Mediterranean、Old World、Shattered 的 Operation、参数和顺序完全一致。`Add 11 all` 与源码 `modify("all", 11, 1)` 的选择、加值和 clamp 行为一致；`land` 的 20 下限行为也一致。

Azgaar 当前源码以 `min === 20` 推导 `isLand`，因此数值范围 `20-max` 也会应用 land 下限。本任务明确把 `range == "land"` 和普通 `min-max` 分开，故实现按显式 target 字符串判断 land；正式六模板仅使用 `Add 11 all`，不受该边缘差异影响。

现有 Hill、Pit、Range、Trough、Strait、Multiply、Smooth、Mask 均未修改。

## Debug View

启动：

```bash
godot --path . tests/worldgen/composition/world_composition_debug_view.tscn
```

- `V`：连续 Continental Value 灰度图。
- `L`：`continental_value >= 20` 宏观轮廓参考图。
- `T`：按正式顺序循环六个 Template。
- `R`：Seed 加一并重新生成。
- 左键：检查 Stable Cell ID 和 continental_value。

界面显示 Template Name、Seed、World Size、Cell Count、生成耗时及五档 Coverage。Debug 场景通过 headless 加载检查。

## 已知问题

- 六模板在 2:1 世界中的视觉质量仍需要图形窗口人工验收；本任务不以 Coverage 或自动规则判断“地图好看”。
- 10011 是现有 grid dimension 算法在 target 10000 和 2:1 比例下的自然结果，不是精确 10000；未为此修改 Spatial 算法。

## 设计偏差

- 相对任务规格：无。
- 相对 Azgaar 的边缘实现：普通数值范围 `20-max` 不被隐式视为 `land`，因为任务明确规定只有 `range == "land"` 使用 20 下限。正式模板行为没有偏差。
